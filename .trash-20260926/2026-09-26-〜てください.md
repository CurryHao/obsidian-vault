# 语法：てください

## 接续
- 动词て形 + ください：書いてください、食べてください
- 否定请求：动词て形 + ください + ない：食べないでください、／ 动词ないて形不行 → 用「～ないでください」
- 礼貌加「を」：动词て形 + ください → ていただいて + 結構です（更客气的转述）

## 核心用法详解

### 请求（请对方做某事）

平辈对平辈、下对上均可使用，是日常的请求默认形。

典型例句：
- ここに名前を書いてください。 — 请在这里写上名字
- 窓を開けてください。 — 请把窗户打开

避坑提示：「てください」是请求，**不是命令**。对长辈、上级用「てください」偏直白，敬语场合用「～ていただけますか」（能不能请您……）。

### 对下指示（上级对下、对晚辈）

上下级关系明确时，「てください」用于指示对方，语气比「～なさい」柔和。

典型例句：
- 先に資料を準備してください。 — 请先准备好资料（对下属）
- 一度確認してから出してください。 — 确认一下再交出来

避坑提示：对陌生人、长辈用「してください」做指示会显得居高临下，改用「～ていただけますか」或直接礼貌请求。

### 否定请求：～ないでください

请对方**不要做**某事。

典型例句：
- 騒がないでください。 — 请不要吵闹
- ここで写真を撮らないでください。 — 请不要在这里拍照

避坑提示：「～ないでください」与「～ませんでください」语义相同，后者更礼貌书面；「～なくてください」是错误形，不能这样接。

## 注意
- 「てください」本身是请求/指示，**不能用来请求自己**：✗ お願いします、てください → ○ お願いします
- 「～てください」与「～てちょうだい」（朋友间请求，更口语随意）语体差异明显，对长辈用「ちょうだい」失礼
- 转述请求：「～てくださいと言われた」（被要求做……），「～てくださいと言う」（要求对方做……）
