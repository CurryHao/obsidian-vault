# 插件发现机制与安装管理

## 📌 一句话总结
> PyTest 的插件生态是其强大生命力的核心。它的插件发现和管理机制设计得非常巧妙，旨在实现“**零配置（Zero-configuration）**”的体验：**你只需要安装它，PyTest 就能自动发现并集成它，无需任何额外的激活步骤**。

## 🎯 核心概念

### 插件的三种形态

在了解发现机制前，首先要知道 PyTest 插件主要有三种存在形式：

1.  **内置插件 (Builtin Plugins)**：随 PyTest 核心一起发布，提供基础功能，位于 `_pytest` 内部目录。
2.  **外部插件 (External Plugins)**：通过 `pip` 安装的第三方包，是最常见的插件形式。
3.  **`conftest.py` 插件**：项目本地的插件文件，用于共享 Fixture 和钩子函数。

### 插件发现顺序：PyTest 启动时的“加载链”

PyTest 在启动时会按照一个严格的顺序来发现和加载插件。理解这个顺序对于诊断插件加载问题至关重要。

1.  **命令行预处理 (`-p no:name`)**：首先扫描命令行，如果存在 `-p no:插件名` 选项，则会**阻止**该插件加载。这个机制甚至可以对内置插件生效。
2.  **加载所有内置插件**：加载 PyTest 自身需要的所有内置插件。
3.  **加载命令行指定插件 (`-p name`)**：扫描命令行中的 `-p 插件名` 选项，并加载指定的插件。
4.  **通过 `setuptools entry points` 发现外部插件**：**这是大多数第三方插件被发现的途径**。PyTest 会扫描所有已安装包中注册的 `pytest11` 入口点。
5.  **加载环境变量 `PYTEST_PLUGINS` 指定的插件**。
6.  **加载 `conftest.py` 文件**：根据命令行参数推断测试路径，并从根目录开始逐级加载 `conftest.py` 文件。
7.  **处理 `pytest_plugins` 变量**：在加载 `conftest.py` 文件后，如果其中定义了 `pytest_plugins` 变量，则会递归加载其中指定的所有插件。

### 插件的安装、使用与管理

#### 1. 安装与卸载

安装和卸载第三方 PyTest 插件与安装普通 Python 包无异，通过 `pip` 命令即可完成。

*   **安装**：`pip install pytest-插件名`
*   **卸载**：`pip uninstall pytest-插件名`

#### 2. 无需激活，自动生效

这是 PyTest 插件机制最便捷的一点。一旦通过 `pip` 成功安装，PyTest 在下次启动时就会通过上述的 **`setuptools entry points`** 机制自动发现并加载它。

#### 3. 在测试模块中要求（Require）插件

你可以在测试模块或 `conftest.py` 文件中通过 `pytest_plugins` 变量来“要求”加载特定的插件。

```python
# 在测试文件或 conftest.py 中
pytest_plugins = ("myapp.testsupport.myplugin",)
```
当这个模块被加载时，`pytest_plugins` 中指定的插件也会被加载。

> **注意**：
> *   在**非根目录**的 `conftest.py` 中使用 `pytest_plugins` 变量已被标记为**废弃（deprecated）**。
> *   `pytest_plugins` 是一个**保留名称**，不应将其用作自定义插件模块的名字。

### 如何发现和评估插件？

PyTest 生态拥有数量庞大的插件，以下是发现和评估它们的途径：

*   **官方插件列表**：PyTest 官网维护了一个**自动更新的插件列表**。它包含了所有在 PyPI 上名称以 `pytest-` 或 `pytest_` 开头的项目。**截至2026年7月，该列表收录了超过 1700 个插件**。
*   **PyPI 搜索**：你也可以直接在 [PyPI](https://pypi.org) 上通过 `pytest-` 关键词进行搜索。
*   **社区推荐**：留意 PyTest 官方文档、博客文章或社区中提到的流行插件。
*   **质量评估**：官方插件列表声明其**并非经过严格审查的精选集合**。在将任何插件集成到项目前，**务必自行评估其质量**，例如检查其维护状态、测试覆盖率、文档完整性和社区活跃度。

### 如何查看当前激活了哪些插件？

可以使用以下命令查看当前 PyTest 环境中已加载和激活的插件列表：

```bash
pytest --trace-config
```
这个命令会输出详细的配置信息，其中就包括所有已加载的插件列表。
