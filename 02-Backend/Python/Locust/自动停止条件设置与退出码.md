# 自动停止条件设置与退出码

在 Locust 中，`--autostop` 和 `--iteration` 并非官方内置参数。实现测试的自动停止，主要依赖 `--run-time` 和 `--stop-timeout` 的组合；而控制进程退出码，则需通过编程方式在脚本中自定义。

### 🛑 自动停止条件的设置

在无界面模式（`--headless`）下，主要通过以下参数控制测试的自动停止：

*   **`--run-time` / `-t`**：设定测试的总运行时长。时间到后，Locust 会尝试停止所有用户。
    ```bash
    locust -f myfile.py --headless -u 100 -r 10 -t 5m
    ```
    上述命令表示测试将在5分钟后停止。

*   **`--stop-timeout`**：设定一个“宽限期”，让正在执行的任务有机会优雅地完成。默认情况下，`--run-time` 时间一到，Locust 会**立即**强硬停止所有任务。使用此参数可避免任务被强制中断。
    ```bash
    locust -f myfile.py --headless -u 100 -r 10 -t 5m --stop-timeout 30
    ```
    这表示在5分钟测试时间结束后，Locust 会等待最多30秒，让当前正在执行的任务完成其迭代。

*   **`--autoquit`**：与 `--autostart` 配合使用，在测试运行结束后，自动退出 Locust 进程。
    ```bash
    locust -f myfile.py --autostart -u 100 -r 10 -t 5m --autoquit 10
    ```
    这表示测试结束后，Locust 进程会在10秒后自动退出。

*   **`--expect-workers`**：在分布式测试中，让 Master 节点等待指定数量的 Worker 节点全部连接成功后，再开始测试。这能确保所有压力节点都已就绪，避免因部分 Worker 未启动而导致压力不足。
    ```bash
    locust -f myfile.py --master --headless --expect-workers=4 -u 100 -r 10
    ```

*   **`--iteration` 的替代方案**：`--iteration` 并非 Locust 的内置参数，它可能来源于其他工具或旧版概念。在 Locust 中，限制用户任务执行次数，通常通过编程方式实现，例如在 `@task` 方法中使用计数器，或在 `SequentialTaskSet` 中控制流程。

### 💻 自定义退出码（Exit Code）

在 CI/CD 中，需要通过退出码来判断压测是否通过。Locust 默认的退出码逻辑较为简单，推荐的做法是在脚本中自定义退出码。

可以通过监听 `quitting` 事件并设置 `environment.process_exit_code` 来实现。当条件不满足时，将退出码设为非0值（如 `1`），CI 系统即可判定为失败。

**示例：基于失败率、平均响应时间、P95 响应时间设置退出码**

```python
# 在你的 locustfile.py 中
import logging
from locust import events

@events.quitting.add_listener
def _(environment, **kw):
    # 1. 检查失败率是否超过 1%
    if environment.stats.total.fail_ratio > 0.01:
        logging.error("Test failed due to failure ratio > 1%")
        environment.process_exit_code = 1
    # 2. 检查平均响应时间是否超过 200ms
    elif environment.stats.total.avg_response_time > 200:
        logging.error("Test failed due to average response time > 200 ms")
        environment.process_exit_code = 1
    # 3. 检查 95 分位响应时间是否超过 800ms
    elif environment.stats.total.get_response_time_percentile(0.95) > 800:
        logging.error("Test failed due to 95th percentile response time > 800 ms")
        environment.process_exit_code = 1
    else:
        # 所有检查通过，退出码为 0
        environment.process_exit_code = 0
```
码会在测试结束时自动执行，并根据设定的性能指标来决定进程的最终退出码。

### 💎 总结

*   **自动停止测试**：主要通过 `--run-time` 设定硬性时间，并配合 `--stop-timeout` 实现优雅停止。
*   **控制退出码**：需要在 `locustfile.py` 中监听 `quitting` 事件，并设置 `environment.process_exit_code`。
*   **`--autoquit`**：用于在测试结束后自动退出进程，适合在自动化脚本中无残留运行。
