# 阶梯式、波浪式、脉冲式负载曲线构建

## 阶梯式/波浪式/脉冲式负载曲线完整构建指南

在性能测试中，负载曲线决定了压力施加的节奏。这三种经典模式分别对应 **容量探测（阶梯式）**、**真实周期性波动（波浪式）** 与 **突发洪峰（脉冲式）**。下面提供可直接运行的 Locust 2.x 实现，附带设计公式、执行命令与调优参数。

---

### 一、阶梯式负载（Step Load）—— 寻找性能拐点

**适用场景**：容量测试、拐点探测、自动扩缩容阈值验证。  
**设计逻辑**：每一阶段维持固定用户数（`hold_time`），在阶段切换时使用平滑爬坡（`ramp_time`），避免瞬断式冲击导致系统误判。

```python
# step_load_shape.py
from locust import LoadTestShape
import math

class StepLoadShape(LoadTestShape):
    """
    阶梯式负载配置
    - 初始用户: 10
    - 每阶梯增加: 50
    - 阶梯保持时间: 120 秒
    - 爬坡过渡时间: 30 秒
    - 最大用户: 1000
    """
    initial_users = 10
    step_size = 50
    hold_time = 120      # 每阶段稳定运行时间（秒）
    ramp_time = 30       # 爬坡过渡时间（秒）
    max_users = 1000

    def tick(self):
        run_time = self.get_run_time()
        
        # 计算当前所处的阶梯阶段（每阶段 = hold + ramp）
        phase_duration = self.hold_time + self.ramp_time
        phase_index = int(run_time // phase_duration)
        
        # 目标用户数（阶梯增长）
        target_users = self.initial_users + phase_index * self.step_size
        target_users = min(target_users, self.max_users)
        
        # 计算在阶段内的偏移时间
        phase_elapsed = run_time % phase_duration
        
        # 爬坡逻辑：在 ramp_time 内线性增长，其他时间保持平稳
        if phase_elapsed < self.ramp_time:
            # 爬坡期：从上一阶梯值爬升到当前目标
            previous_users = self.initial_users + (phase_index - 1) * self.step_size
            if previous_users < 0:
                previous_users = self.initial_users
            progress = phase_elapsed / self.ramp_time
            current_target = int(previous_users + (target_users - previous_users) * progress)
        else:
            # 平稳期：维持目标
            current_target = target_users
        
        # 如果达到最大用户且已经完成最后一个爬坡，维持一段时间后停止
        if target_users >= self.max_users and phase_elapsed > self.hold_time:
            return None  # 测试结束
        
        # 动态调整 spawn_rate：确保在 ramp_time 内完成爬升
        spawn_rate = max(5, self.step_size / self.ramp_time * 1.2)  # 略微超前调度
        
        return current_target, spawn_rate
```
**执行命令**：
```bash
locust -f step_load_shape.py --headless --host=https://api.example.com
# 若文件中还有普通 HttpUser，需指定形状类（-S 参数）
locust -f step_load_shape.py --headless -S StepLoadShape
```

**观察重点**：在 Grafana 中将 RPS/响应时间与阶梯叠加，当响应时间突增或错误率飙升时，对应的用户数即为系统瓶颈拐点。

### 二、波浪式负载（Wave Load）—— 模拟自然周期性流量

**适用场景**：线上真实业务日周期波动（早晚高峰）、定时任务触发、物联网设备周期性上报。  
**设计逻辑**：使用正弦函数（或余弦）平滑变化，支持叠加多频率谐波模拟复杂曲线。

```python
# wave_load_shape.py
from locust import LoadTestShape
import math

class MultiWaveShape(LoadTestShape):
    """
    复合波浪曲线: 基载 + 主周期波 + 次周期扰动
    """
    base_users = 200          # 基础用户数（谷值）
    primary_amplitude = 300   # 主波振幅（峰值 = base + amp = 500）
    primary_period = 600      # 主波周期（秒），例如 10 分钟
    secondary_amplitude = 50  # 次波振幅（模拟突发小波动）
    secondary_period = 90     # 次波周期（秒），例如 1.5 分钟
    spawn_rate_limit = 50     # 最大启动速率限制

    def tick(self):
        t = self.get_run_time()
        
        # 主波：低频大波动
        primary_wave = self.primary_amplitude * math.sin(2 * math.pi * t / self.primary_period)
        
        # 次波：高频小波动（叠加余弦制造不对称）
        secondary_wave = self.secondary_amplitude * math.cos(2 * math.pi * t / self.secondary_period + 0.5)
        
        # 计算目标用户数（确保不低于 10）
        target_users = self.base_users + primary_wave + secondary_wave
        target_users = max(10, int(target_users))
        
        # 自适应 spawn_rate：根据变化率动态调整
        # 导数近似: (target - current) / 某个时间常数
        # 这里简化，使用与变化幅度成正比的速率
        rate = abs(self.primary_amplitude * 2 * math.pi / self.primary_period) + 5
        spawn_rate = min(self.spawn_rate_limit, max(10, int(rate * 1.5)))
        
        return target_users, spawn_rate

# 如果需要模拟“午休下降 + 晚间高峰”的非对称日曲线，可扩展为分段周期函数
class DiurnalWaveShape(LoadTestShape):
    """
    非对称日周期：早高峰爬升快，晚高峰下降慢，午间小憩。
    """
    def tick(self):
        t = self.get_run_time() % 86400  # 24 小时周期
        
        # 定义关键时间点（秒）与权重系数
        schedule = [
            (0, 0.2),      # 00:00 低点
            (28800, 0.8),  # 08:00 早高峰
            (43200, 0.5),  # 12:00 午间回落
            (64800, 1.0),  # 18:00 晚高峰
            (79200, 0.6),  # 22:00 开始下降
            (86400, 0.2)   # 24:00 回到低点
        ]
        
        # 线性插值计算当前权重
        for i in range(len(schedule) - 1):
            t_start, w_start = schedule[i]
            t_end, w_end = schedule[i + 1]
            if t_start <= t < t_end:
                progress = (t - t_start) / (t_end - t_start)
                weight = w_start + (w_end - w_start) * progress
                break
        else:
            weight = schedule[-1][1]
        
        max_users = 3000
        target_users = int(max_users * weight)
        spawn_rate = max(5, abs(target_users - (self.runner.user_count if self.runner else 0)) / 10)
        
        return target_users, spawn_rate
```

**执行命令**：
```bash
# 运行复合波浪
locust -f wave_load_shape.py --headless -S MultiWaveShape -t 30m  # 运行30分钟观察周期
# 输出CSV便于画图对比
locust -f wave_load_shape.py --headless -S MultiWaveShape --csv=wave_result
```

**调优建议**：若波浪频率过快导致启动速率跟不上，可增大 `spawn_rate_limit` 或降低周期频率。

### 三、脉冲式负载（Pulse/Spike Load）—— 模拟秒杀/突发流量

**适用场景**：电商秒杀、抢票、限时活动、DDOS 攻击模拟（安全测试）。  
**设计逻辑**：快速爬升至峰值，维持极短时间，然后迅速回落，形成“方波”或“尖峰”。

```python
# spike_load_shape.py
from locust import LoadTestShape

class SquarePulseShape(LoadTestShape):
    """
    标准方波脉冲：基线 50，峰值 5000，脉冲持续 30 秒，间隔 90 秒
    """
    baseline = 50
    peak = 5000
    pulse_duration = 30    # 脉冲持续秒数
    interval = 120         # 脉冲间隔周期（秒），含 pulse_duration
    ramp_up_seconds = 10   # 爬升时间（秒）
    ramp_down_seconds = 10 # 下降时间（秒）

    def tick(self):
        t = self.get_run_time()
        
        # 计算在周期内的位置
        cycle_time = t % self.interval
        
        if cycle_time < self.ramp_up_seconds:
            # 上升沿：从基线到峰值
            progress = cycle_time / self.ramp_up_seconds
            target = int(self.baseline + (self.peak - self.baseline) * progress)
            spawn_rate = (self.peak - self.baseline) / self.ramp_up_seconds * 2
        elif cycle_time < self.ramp_up_seconds + self.pulse_duration:
            # 脉冲维持阶段
            target = self.peak
            spawn_rate = 0  # 维持高并发
        elif cycle_time < self.ramp_up_seconds + self.pulse_duration + self.ramp_down_seconds:
            # 下降沿：从峰值回落到基线
            progress = (cycle_time - self.ramp_up_seconds - self.pulse_duration) / self.ramp_down_seconds
            target = int(self.peak - (self.peak - self.baseline) * progress)
            spawn_rate = (self.peak - self.baseline) / self.ramp_down_seconds * 2
        else:
            # 空闲期：保持基线
            target = self.baseline
            spawn_rate = 0
        
        # 防止负值
        target = max(1, target)
        return target, int(spawn_rate) + 1

class ExponentialSpikeShape(LoadTestShape):
    """
    指数脉冲：模拟瞬间流量尖峰（如整点抢购），尖峰呈指数级爆发
    """
    base = 100
    peak = 10000
    spike_center = 300    # 第300秒触发秒杀
    sharpness = 0.05      # 尖锐度（越大越陡）

    def tick(self):
        t = self.get_run_time()
        
        # 高斯脉冲公式: peak * exp(-((t - center)^2) / (2 * sigma^2))
        # 使用指数衰减模拟比高斯更陡峭的上升
        diff = t - self.spike_center
        if diff < 0:
            # 陡峭上升
            factor = math.exp(diff * self.sharpness * 2) if diff > -20 else 0
        else:
            # 陡峭下降（更快的衰减）
            factor = math.exp(-diff * self.sharpness * 3)
        
        spike_value = self.peak * factor
        target = int(self.base + spike_value)
        target = max(self.base, target)  # 不低于基线
        
        # 动态spawn_rate确保迅速达到峰值
        current_users = self.runner.user_count if self.runner else 0
        spawn_rate = abs(target - current_users) / 2 + 10
        
        return min(target, 20000), int(min(spawn_rate, 1000))
```

**执行命令**：
```bash
# 运行方波脉冲（适合观察限流和熔断效果）
locust -f spike_load_shape.py --headless -S SquarePulseShape -t 10m

# 指定运行特定 HttpUser 标签（只压测秒杀接口）
locust -f spike_load_shape.py --headless -S SquarePulseShape --tags seckill
```

**关键指标**：重点关注脉冲期间的 **P99 响应时间** 和 **错误率（超时/限流/库存不足）**。若错误率超过 1%，说明系统需要弹性扩容。

### 四、组合高级模式：阶梯 + 波浪（模拟大促叠加日周期）

在大促日（如双 11），负载既有日周期趋势，又有整点秒杀脉冲。可通过组合类实现：

```python
class ComboShape(LoadTestShape):
    def tick(self):
        t = self.get_run_time()
        # 1. 基础日周期（24小时）
        diurnal_base = 200 + 300 * math.sin(2 * math.pi * (t % 86400) / 86400 - math.pi/2)
        
        # 2. 整点脉冲（每3600秒触发一次，持续60秒）
        hour_mod = t % 3600
        spike_add = 0
        if hour_mod < 60:  # 整点后60秒
            spike_add = 5000 * (1 - hour_mod / 60)  # 快速衰减
        
        target = int(diurnal_base + spike_add)
        spawn_rate = 100 if spike_add > 1000 else 20
        return max(10, target), spawn_rate
```

### 五、验证与调试技巧

| 验证方法 | 命令/操作 | 预期结果 |
|---------|----------|---------|
| 打印实时目标 | 在 `tick()` 中添加 `print(f"t={t:.0f}, users={target}")` | 观察曲线是否符合设计 |
| 图形化验证 | 将 `--csv=result` 输出的 `*_stats_history.csv` 导入 Excel 绘制折线图 | 查看 `UserCount` 列与实际设定对比 |
| 分布式同步检查 | 在 Master 日志中查看 `Starting ... users` | 确认形状在 Master 计算，Worker 跟随 |
| 资源预判 | 根据峰值用户数（如 10000）估算 Worker 数量：单 Worker 建议不超过 500-1000 用户 | 防止压测机自身成为瓶颈 |

### 六、常见陷阱与解决

| 陷阱 | 现象 | 解决方案 |
|------|------|----------|
| **Spawn_rate 过小导致达不到目标** | 图中曲线迟迟达不到设定峰值 | 将 `spawn_rate` 设为 `(target - current) / ramp_time * 1.2` |
| **Spawn_rate 过大导致连接失败** | 大量 `ConnectionRefusedError` | 降低 `spawn_rate`，增加爬坡时间 `ramp_time` |
| **脉冲期间 CPU 跑满但 RPS 不增** | 压测机自身成为瓶颈 | 增加 Worker 节点或使用 `--processes` 多进程 |
| **形状运行一段时间后自动退出** | 返回了 `None` | 检查返回 `None` 的条件逻辑（如 `target >= max_users`） |
| **Web UI 模式看不到形状效果** | 界面用户数可手动调 | 必须使用 `--headless` 模式运行形状 |

### 七、下一步实践建议

1. **将负载曲线与断言结合**：在脉冲峰值时，断言 `失败率 < 5%`，否则测试标记为失败并触发告警。
2. **曲线参数外部化**：通过 `--shape-args` 或环境变量传入峰值、周期等，避免硬编码。
3. **集成 CI/CD**：Jenkins/GitLab CI 中运行阶梯测试，自动输出“最大支撑用户数”报告。
