# 手动启停重置测试与用户数动态调整

Locust 提供了三种主要方式来控制测试生命周期和调整负载，分别适用于交互式调试、自动化流水线和复杂负载模型场景。

### 🖥️ Web UI 控制（最直观，适合交互式调试）

在 Web 界面（默认 `http://localhost:8089`）上，可以方便地控制测试。

*   **启动/调整测试**：在页面顶部的表单中，可以随时修改 **`Number of users`（总用户数）**和 **`Spawn rate`（孵化速率）**，点击 **`Start`** 按钮即可应用新参数开始或调整测试。
*   **停止测试**：点击 **`STOP`** 按钮会立即停止所有用户，不再发起新请求。若需优雅停止，可在启动命令中加入 `--stop-timeout` 参数，给正在运行的任务一个缓冲时间。
*   **重置统计数据**：点击 **`Reset Stats`** 按钮会清空当前所有统计图表和计数，便于开始新一轮观察，但**不会**停止或重置测试本身。

### ⌨️ 命令行控制（适合 CI/CD 自动化）

在无界面模式（`--headless`）下，主要通过命令行参数和键盘快捷键控制。

*   **预设运行时长**：使用 `-t` 或 `--run-time` 参数，测试将在指定时间后自动停止。
    ```bash
    locust -f myfile.py --headless -u 100 -r 10 -t 5m
    ```
*   **动态调整用户数（键盘快捷键）**：在运行中的 `headless` 终端里，可以直接按键调整用户数。
    *   `w`：增加 1 个用户
    *   `W`：增加 10 个用户
    *   `s`：减少 1 个用户
    *   `S`：减少 10 个用户
*   **自动退出**：使用 `--autoquit` 参数，可在测试结束后等待指定秒数自动退出。
    ```bash
    locust -f myfile.py --headless -u 100 -r 10 -t 5m --autoquit 10
    ```

### ⚙️ 编程式控制（最灵活，适合复杂场景）

在 Python 脚本内部，可以通过事件监听或 API 实现更精细的控制。

*   **使用 `LoadTestShape` 实现动态曲线**：通过定义 `tick()` 方法，可以在测试运行过程中动态返回期望的用户数和孵化速率，实现脉冲、阶梯等复杂负载模型。
    ```python
    from locust import LoadTestShape

    class MyShape(LoadTestShape):
        def tick(self):
            run_time = self.get_run_time()
            if run_time < 60:
                return (100, 10)  # 前60秒，100用户，每秒孵化10个
            elif run_time < 120:
                return (50, 5)   # 60-120秒，降低到50用户
            else:
                return None      # 停止测试
    ```
*   **通过 API 端点控制**：Web UI 的后台本质上是 REST API，可以通过编程方式调用。例如，用 `curl` 停止测试并重置统计：
    ```bash
    # 停止测试
    curl http://localhost:8089/stop
    # 重置统计数据
    curl http://localhost:8089/stats/reset
    ```

### 💎 总结与注意事项

| 控制方式 | 启动测试 | 停止测试 | 动态调整用户数 | 重置统计 |
| :--- | :--- | :--- | :--- | :--- |
| **Web UI** | 点击 `START` | 点击 `STOP` | 修改参数后再次 `START` | 点击 `Reset Stats` |
| **命令行 (Headless)** | `--headless` 启动 | `Ctrl+C` 或 `-t` 设定时长 | 键盘快捷键 `w/W/s/S` | 重启测试 |
| **编程 (Shape/API)** | 调用 `/swarm` API | `tick()` 返回 `None`或调用 `/stop` API | `tick()` 动态返回元组 | 调用 `/stats/reset` API |

*   **重置统计 vs. 重置测试**：`Reset Stats` 只清零数据，不停止用户。若想完全重置，需先 `STOP` 再 `START`。
*   **动态调整的限制**：通过 Web UI 修改用户数会**重启**测试，导致所有用户重新孵化。若需无中断的平滑调整，应使用 `LoadTestShape` 或键盘快捷键。
*   **Web UI 的 `--autostart`**：该参数可在启动 Web UI 的同时自动开始测试，兼顾了可视化监控和自动化启动的需求。

选择哪种控制方式，取决于你的具体场景：交互式调试用 Web UI，自动化集成用命令行，而复杂的负载模型则非 `LoadTestShape` 莫属。
