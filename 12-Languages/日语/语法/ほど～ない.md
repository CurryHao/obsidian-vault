# 语法：ほど～ない

## 接续
- 名词 + ほど + 形容词/动词否定形
- 动词普通形 + ほど + 否定形
- 公式：`A は B ほど + 形容词否定形 / 动词否定形`
- 核心逻辑：「ほど」表示程度，句尾否定，意思是「没有达到B的那种程度」，即 **A 的程度 < B 的程度**

## 核心用法详解

### 用法一：一般比较（A不如B……）
表示 A 在某个属性上不如 B，是「～より」的反义表达。

典型例句：
- 今年は去年ほど暑くない — 今年夏天不如去年热
- この問題はあの問題ほど簡単ではない — 这道题没有那道题那么简单
- 私は彼ほど日本語が上手ではない — 我没有他日语那么好
- 今日は昨日ほど寒くない — 今天没有昨天那么冷

### 用法二：与预期比较（没有想象中那么……）
表示实际情况未达到说话人原本的预期。

典型例句：
- この映画は思ったほど面白くなかった — 这部电影没有想象的那么有趣
- テストは心配したほど難しくなかった — 考试没有我担心的那么难
- 思ったほど勉強しなかった — 没有想的那样用功

### 用法三：最高级表达（没有比……更……的了）
当「ほど」前接これ/あれ/こんなに等极端程度的指示词时，否定句表达最高级含义，即「其他一切都不如这个」。

典型例句：
- これほど嬉しいことはない — 没有比这更开心的事了
- あれほど美味しい料理は初めてだ — 没有比那更好吃的菜了
- こんなに困ることはない — 没有比这更让人为难的了

## 注意
- **与「～より」的对比**：「より」是 A > B（正向比较），「ほど～ない」是 A < B（反向比较），两者语义相反
- **句尾必须用否定**：「ほど」单独使用表示「达到……程度」，要表达「不如」句尾必须有否定
- **助词错误**：「ほど」前直接接比较基准名词，不需要加「が」或「は」，正确的是「彼ほど」不是「彼がほど」
- **动词接续**：动词可以直接接「ほど」，不需要名词化，如「思ったほど」而不是「思ったことほど」
- **与「～くらい」的区别**：「ほど」偏正式/书面，程度感较高或较精准；「くらい」偏口语，程度感较低或模糊
