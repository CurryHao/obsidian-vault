# 语法：Nがある／いる（存在）

## 接续
- 无生命物 + が + ある：テレビがあります
- 有生命体 + が + いる：猫がいます
- 处所 + に + 存在物：教室**に**テレビが**ある**

## 核心用法详解

### 无生命存在（ある）
表示物品、场所等无生命事物的存在。

典型例句：
- 教室にテレビがあります — 教室里有电视
- 冷蔵庫に卵がありません — 冰箱里没有鸡蛋（否定）

避坑提示：存在句里存在物用「が」标记，不是「を」：✗ 教室にテレビをあります。

### 有生命存在（いる）
人、动物等能自主移动的有生命体存在用「いる」。

典型例句：
- 部屋に猫がいます — 房间里有猫
- 教室に先生がいます — 教室里有老师

避坑提示：判断「ある/いる」看**是否自主移动**，不看是否「活物」：树、花固定不动用「ある」（庭に木がある）；鱼、鸟能移动用「いる」。

### 处所助词「に」
存在处所一律用「に」标记，是存在句的骨架：「どこに何がどうある/いる」。

典型例句：
- 机の上に本があります — 书桌上有本书
- 駅の下にコンビニがあります — 车站下面有家便利店

避坑提示：「に」在这里表存在位置，别与表时间点的「に」混为一谈（虽同为「に」但功能不同）。

## 注意
- 高频易错点：ある/いる 的判定（自主移动）；存在物助词「が」；处所「に」
- 语体限制：あります/います 为礼貌体；ある/いる 为普通体
- 与「～に＋动词」的不可替换场景：存在句不能用动作动词替代（✗ 教室にテレビを置くあります），要表达「某人摆放」则换主动句
