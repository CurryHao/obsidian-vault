# 语法：Nがほしい

## 接续
- 名词 + が + ほしい：本がほしい
- 礼貌形：名词 + が + ほしいです
- 过去：名词 + が + 欲しかった（「ほしい」本身是イ形容词，过去式活用）

注意：「ほしい」是形容词，修饰名词用「ほしい本」，但"想要的对象"作主语时用「Nがほしい」。

## 核心用法详解

### 想要具体事物（物欲）

对物品、金钱等具体存在的东西表达"想要"。

典型例句：
- 新しいパソコンがほしいです。 — 我想要一台新电脑
- 冬が来る前に、暖かいコートを一枚買い置きしておきたいから、少し予算がほしい。 — 想在入冬前买件厚外套存着，所以想留一点预算

避坑提示：「ほしい」的对象是**名词**（具体的东西）；"想做某事"（动作）用「动词ます形去ます + たい」。混用是 N5 高频错误：✗ 食べほしい → ○ 食べたい。

### 口语与谦让场合的替换

「ほしい」日常可用，但向长辈/上级表达"想要"时偏直白，敬语场合用「～ていただきたいと思います」（希望得到）更得体。

典型例句：
- 上司：資料のコピーを頂戴できますか。 — 能否请您给我一份资料复印件（正式）
- 朋友之间：コピーがほしい。 — 我想要一份复印件（口语）

避坑提示：「ほしいです」比「ほしい」礼貌一档，但仍是日常语感；商务邮件、对客户的表达里「ほしいです」也显得太直白。

## 注意
- 「ほしい」的对象格助词是「が」（不是「を」）：✗ 本をほしい → ○ 本がほしい
- 礼貌形只加「です」，「ほしい」本身不变形：✗ ほしいます → ○ ほしいです
- 「～てほしい」（N3）方向相反：是"我希望**别人**为我做某事"，不是"我想要东西"

## 相似语法
- [[てほしい]]（N3 希望别人做某事；与「Nがほしい」同为"想要"系，但对象是动作且方向相反）
- [[ようにする]]（N4 主动坚持做某事，愿望的"实现动作"侧）
