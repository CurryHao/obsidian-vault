# 语法：動詞のて形（Vて形）

## 接续
- 动词て形（连用形）
- た形由て形转换：て→た、で→だ（書いて→書いた、読んで→読んだ），无需另记变形

## 变形规则

### 二类动词（一段）
去掉词尾「る」加「て」：食べる→食べて、見る→見て

### 一类动词（五段）
- 词尾「う・つ・る」：促音变 → って（買う→買って、待つ→待って、帰る→帰って）
- 词尾「む・ぶ・ぬ」：拨音变 → んで（飲む→飲んで、死ぬ→死んで）
- 词尾「く」：イ音变 → いて（書く→書いて）
- 词尾「ぐ」：イ音变 → いで（泳ぐ→泳いで）
- 词尾「す」：直接 → して（話す→話して）

### 三类动词（カ変・サ変）
- 来る→来て（きて）
- する→して（勉強する→勉強して）

### 唯一特殊例外
- 行く→行って（不按「く→いて」规则）

## 核心用法详解

### 中顿（动作串联）
把多个连续动作串成长句，避免短句生硬。
- 朝起きて、顔を洗って、ご飯を食べて、学校へ行きます。 — 早上起床、洗脸、吃饭，然后去学校。

### 搭配高频句型
- ～てください：礼貌请求/命令 — ここに名前を書いてください。请在这里写下名字。
- ～ている：进行/状态 — 今、本を読んでいます。／彼は結婚しています。
- ～てもいい：许可 — ここで写真を撮ってもいいですか。
- ～てはいけません：禁止 — 図書館で大きな声で話してはいけません。
- ～てみる：尝试 — 日本語で話してみます。
- 授受补助动词 ～てあげる／てくれる／てもらう — 友達にプレゼントを買ってあげます。
- 移动补助动词 ～ていく／てくる — ちょっと買い物してきます。

## 注意
- 中顿表原因时，后句不能接意志类表达（～てください／～ましょう），否则语法错误
- た形可直接由て形转换，不必重记变形
