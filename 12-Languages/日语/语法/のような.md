# 文法：～のような

## 繋ぎ方
- 名詞 + のような + 名詞
- 動詞普通形 + ような + 名詞
- い形容詞普通形 + ような + 名詞
- な形容詞詞幹 + な + ような + 名詞（例：きれいなような）

## 核心的な用法

### 比喻
AをBに例え、形容する。話者の主観的な印象に基づく。

典型例文：
- 彼は鉄のような意志を持っている — 他有着钢铁般的意志
- 雪のような肌 — 雪白的肌肤

### 例示（代表性の例を挙げる）
同じカテゴリから代表的な例を示し、「……のような……」と述べる。

典型例文：
- 京都や奈良のような古都を訪ねたい — 我想去拜访像京都、奈良这样的古都

### 不確かな判断・推測（委婉表現）
断定を避け、話者の感覚・憶測を表す。「聞いた話だ」より柔らかいニュアンス。

典型例文：
- どこかで聞いたような話だ — 这故事好像在哪儿听过
- 彼には、何か隠しているようなところがある — 他好像有什么事情瞒着

### 内容指示（抽象と具体を繋ぐ）
前に述べた内容を「ような」で指し示し、名詞を修飾する。

典型例文：
- 彼が言ったようなことを、私も感じた — 我也感觉到了他所说的那种情况

## 注意
- **名詞を修飾する**：「ような」は連体形なので、後に必ず名詞が続く。結句で使うのは「ようだ」。
- **「～のように」との違い**：
  - 「ような + 名詞」→ 定语修饰名词（雪のような肌）
  - 「ように + 用言」→ 状语修饰动词/形容词（雪のように白い / 彼のように頑張りたい）
  - 簡単な覚え方：**"ような名、ように动"**
- **「～みたいな」との違い**：「みたいな」は「ようだ」の口語的・随意的表現。正式な文章では「ようだ」を使う。名詞に直接付ける場合「みたいな」は「の」不要（鉄みたいな意志）。
- **「～らしい」との違い**：
  - 「ような」→ 話者の主観的感覚・印象（我感觉像……）
  - 「らしい」→ 客観的根拠・伝聞・典型的特徴に基づく推測（有迹象/听说/具备……的典型特点）
  - 例：彼は学生ような格好をしている（見ての印象）／彼は学生らしい（見た目や言動から判断）
