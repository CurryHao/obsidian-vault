# 语法：～まえに

## 接续
- 動詞：V辞書形 ＋ まえに：寝る ＋ まえに
- 名詞：N ＋ の ＋ まえに：授業 ＋ の ＋ まえに

## 核心用法详解

### 用法一：时间先后（在……之前）
描述一个动作/状态发生在另一个动作之前，语感核心是「先做前项，后项在其之前完成」或「趁前项还没开始/还没变化先做某事」。

典型例句：
- 寝るまえに、歯磨きをする。 — 睡觉前刷牙
- ご飯を食べるまえに、薬を飲む。 — 吃饭前吃药
- 授業のまえに、先生に質問をする。 — 上课前向老师提问
- 日本に帰る前に、土産を買う。 — 回日本前买点土特产（自拟）

### 用法二：习惯性、反复发生的动作
与「毎日」「毎朝」等常习惯表达搭配，描述反复出现的固定顺序。

典型例句：
- 毎朝、家を出る前にトイレに行く。 — 每天早上出门前上厕所
- 学校に行く前に、喫茶店でコーヒーを飲む。 — 去学校前在咖啡店喝杯咖啡
- 寝る前にスマホを見るのが癖です。 — 睡前看手机成了习惯（自拟）

避坑提示：接「まえに」的动词必须用辞书形，不能用て形（✗ 食べるまえに）；名词必须加「の」（✗ 授業まえに）。

## 注意
- 书写变体：口语/书面常见「前に」「の前に」，与「まえに」同义
- 时间顺序与「～てから」相反：～てから＝先A后B；～まえに＝B在A之前
- 句子变过去时，前后两个动作都落过去：寝る前に歯磨きを**した**
- 「～まえに」后接的通常是说话人自己能控制的动作（刷牙、吃药、提问）

## 相似语法
- [[～てから]]（先A后B，与「～まえに」时间顺序相反）
