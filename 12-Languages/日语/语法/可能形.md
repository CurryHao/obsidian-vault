# 语法：可能形（れる・られる）

## 接续

可能形的本质是「动词辞书形 → 另一组动词活用」。三大类别规则如下：

| 类别 | 变形规则 | 例 |
|------|---------|----|
| 一类（五段）动词 | 词尾假名变成对应**え段**假名 + る | 行く → 行**ける**、飲む → 飲**める**、話す → 話**せる**、書く → 書**ける** |
| 二类（一段）动词 | 去掉词尾「る」+ **られる** | 食べる → 食べ**られる**、見る → 見**られる**、起きる → 起き**られる** |
| 三类动词 | する → **できる**、来る → **来（こ）られる** | 勉強する → 勉強**できる**、来る → 来**られる** |

礼貌体直接后续「ます／ました／ません／ました」等礼貌助动词：

| 时态/语气 | 形态 |
|-----------|------|
| 现在时礼貌体 | 行**けます**／食べ**られます**／勉強**できます** |
| 过去时礼貌体 | 行**けました**／食べ**られました**／勉強**できました** |
| 否定礼貌体 | 行**けません**／食べ**られません**／勉強**できません** |
| た形（接续用） | 行**けた**／食べ**られた**／勉強**できた** |

## 核心用法详解

### 个人能力（最基础用法）

主语本身具备完成某个动作的能力。常译为「会……」「能……」。

典型例句：
- 私**は**日本語**が**話せます — 我会说日语
- 彼**は**ギター**が**弾けます — 他会弹吉他
- 子供でも**が**この包丁**は**使えます — 小孩也能用这把刀
- 私**は**車の運転**が**できます — 我会开车

避坑提示：能力语义的判定关键是「主语+は+能力对象+が+可能形」，助词搭配见下文第 3 节。

### 客观可能性（外部条件允许）

表示受外部条件（工具、场所、规则、情境）限制，某件事**可以实现**。不是主语的能力，而是外部条件许可。

典型例句：
- このレストラン**で**カード**が**使えます — 这家店可以刷卡（条件允许）
- ここでは携帯**が**使えません — 这里不能用手机（条件禁止）
- 窓**から**山**が**見えます — 从窗户能看到山
- 会議室**で**Wi-Fi**が**使えます — 会议室里能用 Wi-Fi

### 事物固有属性（无生命主语）

主语是事物，描述这个东西本身天然具备某种可实现的属性。主语往往是「水筒／机／この建物……」之类的无生命物。

典型例句：
- この水筒**は**冷たさ**を**長く保てます — 这个保温杯能长时间保冷
- この建物**は**100人収容できます — 这栋建筑能容纳 100 人
- この鍋**は**火**に**かけられます — 这口锅可以上火

### 特殊自动词类可能表达

「見える（看得到）」「聞こえる（听得到）」「分かる（明白）」这类**独立自动词**，专门表达视觉、听觉感官上**自然能捕捉**的状态，不需要人为主动努力。

- 「見える」= 自然映入眼帘（不需主动去看）
- 「聞こえる」= 自然传到耳朵里（不需主动去听）
- 「分かる」= 自然理解、领会

典型例句：
- 窓**から**山**が**見えます — 从窗户能看到山
- 隣の部屋**の**音楽**が**よく聞こえます — 隔壁的音乐听得清清楚楚
- 日本語**が**分かります — 懂日语

避坑提示：**这一类不能用「見れる／聞ける／分れる」**——它们不存在。

## 注意

### 助词核心变化：を → が（90% 的场景）

动词变成可能形之后，原本他动词搭配的格助词「**を**」，绝大多数场景下要替换成「**が**」，直接提示能力/可能性的对象。这是初学者最容易出错的细节点。

| 动词原形 | 可能形 + を（× 错例） | 可能形 + が（○ 正例） |
|----------|----------------------|------------------------|
| 漢字**を**書きます | 漢字**を**書けます ✗ | 漢字**が**書けます ✓ |
| 日本語**を**話します | 日本語**を**話せます ✗ | 日本語**が**話せます ✓ |
| ギター**を**弾きます | ギター**を**弾けます ✗ | ギター**が**弾けます ✓ |
| 水**を**飲みます | 水**を**飲めます ✗ | 水**が**飲めます ✓ |

只有极少数**刻意强调动作对象**的特殊场景才会保留「を」（如对比两个宾语时），日常 90% 以上的常规表达都用「が」。

### 二类动词的「ら抜き言葉」陷阱

二类动词的可能形经常出现**省略「ら」**的口语缩略形式，叫「ら抜き言葉」：

| 标准形 | ら抜き（口语） | 正式场景 |
|--------|----------------|----------|
| 食べ**られる** | 食べ**れる** ✗ 正式 | 考试、书面必用标准形 |
| 見**られる** | 見**れる** ✗ 正式 | 考试、书面必用标准形 |
| 起き**られる** | 起き**れる** ✗ 正式 | 考试、书面必用标准形 |

日常年轻人对话里非常常见，但**正式考试、书面场景里必须使用完整的标准变形**。JLPT N4 听力题里如果出现口语场景，可能听到「食べれる」，但阅读题和书面题永远考标准形。

### 可能形后面不能叠加「を」（最典型中式日语错误）

可能形本身**已经自带「能够」的语义**，后续不能再接他动词的宾语「を」：

- ✗ 日本語**を**話せ**る**こと**を**できます（错三次：保留を + 可能形连用形 + 语义重复）
- ○ 日本語**が**話せます
- ○ 日本語**を**話す**ことが**できます

### 可能形不能与「できる」叠加（语义重复）

- ✗ 話せ**ることが**できます（完全重复）
- ○ 話せます
- ○ 話すことができます
