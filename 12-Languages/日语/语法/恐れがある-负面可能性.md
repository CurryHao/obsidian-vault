# 语法：～恐れがある

## 接续
- 动词辞书形 / 动词ない形 + 恐れがある
- 名词 + の + 恐れがある
- 不能直接接イ形容词、ナ形容词，需先转为名词性表达

## 核心用法详解

### 仅用于负面事态
描述可能发生的负面、不良、有风险的事态，新闻、公告类常见。

典型例句：
- この薬は副作用の恐れがありますので、医者の指示に従って飲んでください。——此药可能存在副作用，请遵医嘱
- 西日本から東日本の広い範囲で大雨や強風の恐れがあります。——大范围可能出现大雨强风

## 注意
- 和「～かもしれない」区别：后者中性通用，前者专指负面
- 和「～可能性がある」区别：后者可覆盖正负向场景，前者自带负面指向
- 仅用于负面风险，不能用于积极向好可能性
- 口语中少用，属硬书面表达
