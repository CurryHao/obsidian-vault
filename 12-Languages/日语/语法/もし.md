# 语法：もし

## 接续
- もし + たら / なら / ば / かもしれない
- 不可与「から」「と」搭配

典型例句：
- もし明日雨が降っ**たら**、試合は中止になる — 如果明天下雨，比赛就取消
- もし日本へ行く**なら**、事前にビザを申請しなければならない — 如果要去日本，必须提前申请签证
- もし安けれ**ば**、このカメラを買おうと思っている — 如果价格合适，我打算买这台相机

## 核心用法详解

### 用法一：强化假定语气
语义：给后续假定句加上强烈的假设语气，明确提示听者接下来讲的是非现实假想场景。可直接省略，省略后假定语义依然成立，只是语气变弱。

典型例句：
- もし私が鳥**なら**、一日中自由に空を飛び回りたい — 我要是是鸟的话，想一整天在天上自由飞
- もし時間が戻せる**なら**、学生時代にもっと勉強したい — 要是时间能倒流的话，想在学生时代更努力学习

避坑提示：「もし」是对话中的假定提示词，听力中听到它就能快速判断后续内容是假设场景，不是既定事实。

### 用法二：高频固定搭配
语义：「もし」几乎只会与4类假定语法组合使用，不同搭配的语气强度有明显差异。

| 搭配 | 语气特征 | 典型场景 |
|------|----------|----------|
| もし + たら | 最口语化，适用最广 | 日常对话、计划讨论 |
| もし + なら | 委婉承接话题 | 给出建议、针对性回应 |
| もし + ば | 书面感强，逻辑严谨 | 理性分析、条件推断 |
| もし + かもしれない | 低概率推测 | 万一、说不定 |

## 注意
- **绝对禁忌**：不可与表确定原因的「から」、表恒常规律的「と」直接搭配
  - × もし雨が降るから、傘を持って行く（错误，语义冲突）
  - ○ もし雨が降ったら、傘を持って行く（正确）
- 口语中「もし」可省略，省略后句意不变，只是假定语气变弱
- **「もしもし」是独立的固定惯用句**：打电话时的专属开场用语"喂喂"，与假定语义完全无关
