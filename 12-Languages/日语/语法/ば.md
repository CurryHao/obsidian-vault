# 语法：～ば

## 接续
- 动词：う段→え段+ば；る段→去掉る+れば；くる→くれば；する→すれば
- い形容词：词尾い→けれ+ば
- な形容词/名词：词干+であれば（口语常简略为なら）

典型例句：
- 行く**ば** → 行け**ば** — 去的话
- 食べる**ば** → 食べれ**ば** — 吃的话
- 痛い**ば** → 痛け**れ**ば — 疼的话
- 静か**ば** → 静か**であれば** — 安静的话

## 核心用法详解

### 用法一：恒常客观条件
语义：描述自然规律、常识、习惯性动作这类必然成立的逻辑关系。条件成立，结果一定会发生。

典型例句：
- 春になれば、花が咲く — 只要到了春天，花就会开
- 長い間本を読めば、目が疲れる — 长时间看书的话，眼睛就会累

避坑提示：此用法与「と」可互换，但「と」更强调客观必然性，「ば」稍带说话人的推断语气。

### 用法二：假定逻辑条件
语义：基于严谨的逻辑推导，提出合理的假定前提，后续多接判断、评价类表达（～いい/～よい/～だめ等）。

典型例句：
- 安ければ、買ってもいい — 如果价格便宜的话，也可以买
- 頭が痛ければ、薬を飲んで寝たほうがいい — 如果头疼的话，吃药睡一觉比较好

避坑提示：后续不可接意志、命令、劝告类表达（这是考试高频考点）。

### 用法三：越……越……（固定句型）
语义：「动词假定形+ば + 同じ动词辞书形+ほど」，表程度随动作推进不断加深。

典型例句：
- 日本語を勉強すればするほど難しくなる — 日语越学越难
- 考えれば考えるほど分からなくなった — 越想越搞不懂

避坑提示：此句型为高考/JLPT必考固定搭配，变形规则是核心考点，注意「すればするほど」不能写成「するするほど」或「すればほど」。

## 注意
- 四大假定语法中，「ば」的动词变形规则最特殊（う段→え段），是考试重点
- 核心禁忌：**当前后句主语一致，且前半句是说话人刻意做出的意志性动作时，不能使用「ば」**
  - × 明日行けば、映画を見ます（前后主语一致，前半为意志行为）
  - ○ 明日行ったら、映画を見ます / 明日行けば、天気が良くなります（客观条件可）
- 「ば」后续多为判断、评价、推测，不可接意志・命令・勧誘
- 口语中「であれば」常被简略为「なら」，但正式书面场景需保留完整形式
