# 语法：意志形（～おう・～よう・～しよう）

## 接续

可能形另一组活用是**意志形**——本质是「动词辞书形 → 表达意志的活用」。三大类别规则：

| 类别 | 变形规则 | 例 |
|------|---------|----|
| 一类（五段）动词 | 词尾假名变成对应**お段**假名 + う | 行く → 行**こう**、飲む → 飲**もう**、話す → 話**そう**、買う → 買**おう** |
| 二类（一段）动词 | 去掉词尾「る」+ **よう** | 食べる → 食べ**よう**、見る → 見**よう**、起きる → 起き**よう** |
| 三类动词 | する → **しよう**、来る → **来（こ）よう** | 勉強する → 勉強**しよう**、来る → 来**よう** |

礼貌体是「～ましょう」（一类）/「～ましょう」（二类）/「～しましょう」（三类）统一形式。礼貌体后续「～ました」表过去意志决心。

| 时态/语气 | 一类例 | 二类例 | 三类例 |
|-----------|--------|--------|--------|
| 现在时简体 | 行**こう** | 食べ**よう** | 勉強**しよう** |
| 现在时礼貌体 | 行**きましょう** | 食べ**ましょう** | 勉強**しましょう** |
| 过去时礼貌体 | 行**きましょうでした**（极少用） | 食べ**ましょうでした** | 勉強**しましょうでした** |

## 核心用法详解

### 个人当下的行动决心（简体独白）

多用于**自言自语、当场做出决定**的场景，传递「我现在就下定决心要做这件事」的即时意志。简体最随意，独白场景常用。

典型例句：
- 疲れたから、今日は早く帰**ろう** — 太累了，今天早点回家吧
- もう一回挑戦し**よう** — 再挑战一次吧
- そろそろ行**こう** — 差不多该走了

避坑提示：这一用法**仅限私下独白或非常熟的朋友之间**，对上司、陌生人用简体「～よう」会显得非常失礼、孩子气（见下文易错点）。

### 礼貌体「～ましょう」：共同行动号召

礼貌体「～ましょう」是**职场、日常社交里最安全的邀约表达**，用来邀请对方一起做某事。语感上等于"我们一起……吧"。

典型例句：
- 一緒に昼ご飯を食べに行**きましょう** — 我们一起去吃午饭吧
- そろそろ出発し**ましょう** — 我们差不多该出发了
- もう一度検討し**ましょう** — 我们再讨论一次吧
- 乾杯し**ましょう** — 我们干杯吧

适用场景：会议开场邀约、同事日常邀约、商务接待、寒暄用语。礼貌、得体、不冒犯。

### 后续搭配衍生语法（核心使用场景）

单独使用意志形的场景相对有限，**绝大多数日常使用里，意志形都会后续接「と思う」「とする」「と思っている」**等结构，形成更丰富的意向表达：

| 衍生结构 | 核心语义 | 时间感 |
|----------|---------|--------|
| ～よう**と思う** | 当下萌生的临时打算 | 瞬时、单次 |
| ～よう**と思っている** | 持续酝酿的稳定意向 | 长期、已考虑一段时间 |
| ～よう**とする** | 动作即将发生、处于准备启动状态 | 即将、非主观 |
| ～よう**としたら** | 刚要……时（与「たとたん」辨析） | 瞬间 |

详细对比见 [[～ようと思っている]]，单独条目已展开。

## 注意

### 三大核心场景与近义表达的语感对比

| 表达形式 | 核心特征 | 适用场景 | 礼貌程度 |
|----------|----------|----------|----------|
| 意志形单用（～よう／～おう） | 当下瞬间的冲动、自言自语的念头 | 私下独白、非常熟的朋友 | 简体、非常随意 |
| ～ましょう | 礼貌的共同行动号召 | 职场、普通社交邀约 | 礼貌体、得体通用 |
| ～ようと思う | 当场形成的明确打算 | 告知他人自己当下的决定 | 礼貌自然 |
| ～ようと思っている | 持续酝酿中的稳定意向 | 分享初步意向、长期考虑 | 礼貌、措辞柔和 |
| ～ようとする | 动作即将发生、准备启动 | 描述非主观的即将发生 | 客观陈述 |
| ～つもりだ | 已经敲定的长期计划 | 告知他人提前做好的安排 | 计划确定度更高 |

时态/确定性递进：**意志形单用（瞬时）< ～ようとする（即将）< ～ようと思う（当场决定）< ～ようと思っている（酝酿）< ～つもりだ（已决定）**。

### 主语限制：第一人称为主

意志形的主语**只能是自己**（第一人称）。要描述第三人称的意志，必须后续补充传闻、引用类结构：

- ○ 私**は**帰**ろう**（我自己决定回去 / 第一人称）
- ✗ 田中さんは帰**ろう**（直接描述第三人称意志 / 错例）
- ○ 田中さんは帰**ろうとしているそうだ**（听说田中正准备回去 / 传闻引用）
- ○ 田中さんは帰**ろうと思っていると言っていた**（田中说他准备回去 / 直接引用）
- ○ 田中さんは帰る**つもりだそうだ**（听说田中打算回去）

### 不能用于描述长期未来计划

意志形单用**不能用来描述长期的未来计划**——它只表达当下瞬间的意志。描述长期打算必须后续接续体结构：

- ✗ 来年留学し**よう**（错例：单用听起来像"我现在要留学"的瞬时意志，与"明年"的时间矛盾）
- ○ 来年留学し**ようと思っています**（我打算明年留学 / 持续意向）
- ○ 来年留学する**つもりです**（我明年打算留学 / 已决定）
