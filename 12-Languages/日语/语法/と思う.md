# 语法：と思う

## 接续

直接接在**简体形句子**的末尾。不管简体句由动词、イ形容词、ナ形容词、名词哪种词类构成，都能直接后续「と思う」：

| 简体句类型 | 简体形结构 | 接续例 |
|-----------|----------|-------|
| 动词简体 | 辞书形／た形／ない形／なかった形 | 明日**は雨が降る**と思う、昨日**映画を見た**と思う |
| イ形容词简体 | 词干 + い／くない／かった／なかった | このレストラン**の料理は美味しい**と思う |
| ナ形容词简体 | 词干 + だ／じゃない／だった／じゃなかった | 彼**は真面目だ**と思う |
| 名词简体 | 名词 + だ／じゃない／だった／じゃなかった | 彼**は学生だ**と思う |

礼貌体用「～と思います／と思いました／～と思いません／～と思いませんでした」。注意礼貌体**只把句末的「思う」变成「思います」**，前项简体保持不变——这是最常考的反直觉点：

- ✗ 明日は雨が降ります**と思います**（错：前项不该用礼貌体）
- ○ 明日は雨が降る**と思います**（正：前项简体 + 句末礼貌体）

## 核心用法详解

### 当下瞬间的主观判断（核心义）

直接传递说话人当下瞬间的主观判断、个人意见，是日语里最直白的「我认为」类表达。**没有额外的附加语感**，完全是说话人当下直接说出自己的想法。

典型例句：
- 明日**は雨が降る**と思う — 我觉得明天会下雨
- このレストラン**の料理は美味しい**と思う — 我觉得这家店的菜很好吃
- 田中さん**は来る**と思う — 我觉得田中会来
- これ**は一番いい方法だ**と思う — 我觉得这是最好的方法

避坑提示：**仅限说话人当场表达自己当下的想法**，不能用来陈述客观事实或长期持有的判断。

### 软化主张的委婉表达

日语里表达意见时，常用「～と思う」来**软化自己的主张**，避免语气过于强硬，是非常常用的委婉技巧。中文里通常对应「我觉得……」「我认为……」。

典型例句：
- この案**が一番いい**と思う — 我觉得这个方案最好
- もう少し考えたほうがいい**と思う** — 我觉得最好再考虑一下
- その意見**には賛成できない**と思う — 我不太同意那个意见

避坑提示：去掉「～と思う」会显得语气直接、生硬。加上它就带"这只是我的个人看法"的缓冲感，**在职场讨论里几乎是必备的委婉手段**。

### 疑问句里询问对方意见（第二人称专用）

在疑问句中，「～と思う」**可以用于第二人称**，专门用来询问听话人的个人判断。这是「と思う」**唯一**可以突破第一人称限制的场景。

典型例句：
- あなた**はどう思う**？— 你觉得怎么样？
- これ**についてどう思いますか**？— 你对这个怎么看？
- この映画**は面白いと思った**？— 你觉得这部电影好看吗？

避坑提示：**疑问句里的主语必须是第二人称**（あなた／君／お名前），不能写「田中さんはどう思う？」——这是直接询问对方，必须是对话另一方。

### 「と思う」与「と思っている」的核心区分

| 表达 | 时间感 | 主语限制 | 例 |
|------|--------|---------|----|
| ～と思う | **当下瞬间**冒出来的判断，当场直接说出 | 陈述句**只能第一人称**；疑问句可第二人称 | この案が一番いい**と思う**（我当下觉得这个方案最好） |
| ～と思っている | 想法**在脑海里存在了很长时间**，长期持有 | **可描述第三人称**（第三人称须用此结构） | この案が一番いい**と思っている**（我一直以来都觉得这个方案最好） |

关键差异：**「と思う」传达"我现在这么想"，「と思っている」传达"我一直这么认为"**。两者都能表达判断，但持续性和适用范围完全不同。

例句对比：
- 田中さんはこの本**が面白いと思っている**（田中一直以来都觉得这本书有趣 / 描述第三人称）
- ✗ 田中さんはこの本**が面白いと思う**（错：陈述句不能直接第三人称 + 当下瞬间判断不适用于第三人称长期看法）

## 注意

### 人称限制：陈述句只能第一人称

陈述句里「～と思う」**绝对不能直接用来描述第三人称的想法**。要表达第三人称的判断，必须用「～と思っている」。

对照例句：
- ○ 私**は**留学**すると思う**（我自己 / 第一人称）
- ✗ 田中さん**は**留学**すると思う**（错：第三人称直接用「と思う」）
- ○ 田中さん**は**留学**すると思っている**（田中觉得要留学 / 第三人称持续判断）

补充场景：疑问句里询问**第二人称**（对话另一方）是可以的——主语是对方时不受第一人称限制。

### 与「～（よう）と思う」的彻底区分（最易混淆）

这是**两个完全不同的语法**，初学者最容易混淆：

| 表达 | 接续 | 核心语义 | 例 |
|------|------|---------|----|
| ～**简体句** + と思う | 简体句末尾（任意词类简体） | 「我觉得某件事是这样」的**主观判断** | この映画は面白い**と思う**（我觉得这部电影好看） |
| ～**动词意志形** + と思う | 动词意志形 + と思う | 「我打算做某件事」的**行动意向** | 明日映画を見**ようと思う**（我打算明天看电影） |

关键区分点：
- 「我觉得某件事是这样」→ 用普通简体句 + と思う（**没有意志形**）
- 「我打算做某件事」→ 用动词意志形 + と思う（**必须意志形**，与动词原形不同）

例：
- ✗ 明日映画を見**ると思う**（错：用动词辞书形不是意志形，语义成了"我觉得明天要看电影"，不是"我打算看"）
- ○ 明日映画を見**ようと思う**（正：意志形 + と思う = 我打算看）

详见 [[～（よう）と思う]]。

### 主语省略：母语者常省「私は」

陈述句里**默认主语就是第一人称**，所以日语母语者日常表达里经常会省略「私は」：

- ○ 雨が降る**と思う**（我觉得会下雨 / 省略主语完全自然）
- ✗ 雨が降る**と思います私**（错：主语位置不对）
- ○ 私**は**雨が降る**と思う**（强调主语时用）

避坑提示：**省略主语是日语最高频的省略场景之一**——只要用了「～と思う」且是陈述句，主语一定默认是"我"，不需要写出「私は」。

### 高频易错点

**1. 礼貌体只能作用于句末的「思う」**

前项简体形**绝对不能改成礼貌体**：

- ✗ 明日は雨が降**りますと思います**（错：前项不能用「ます」）
- ○ 明日は雨が降**ると思います**（正：前项简体 + 句末礼貌体）

**2. 「～たいと思う」不是「～（よう）と思う」的同义**

- 「～たいと思う」= **想做某事**（个人愿望，可能只是愿望）
- 「～（よう）と思う」= **打算做某事**（经过思考的计划）

例：
- 日本に行**きたいと思う**（我想去日本 / 单纯愿望）
- 日本に行**こうと思う**（我打算去日本 / 已思考过的计划）

**3. 疑问句里询问对方 ≠ 陈述句里第三人称**

- ○ 田中さん**はどう思いますか**（你觉得怎么样？/ 第二人称疑问句）
- ✗ 田中さん**は来ると思う**（错：陈述句不能直接第三人称）

## 相似语法

- [[～（よう）と思う]]（动词意志形 + と思う = 行动意向；与本笔记"主观判断"形成"意向 vs 判断"对照）
- [[～ようと思っている]]（持续体的长期判断 / 意向；适用于第三人称）
- [[つもりだ]]（已经下定决心、形成明确计划——已落在行动层；主观判断是"这件事是这样"，打算是"我要做这件事"）
- [[ことができる]]（与「と思う」无直接关联，vault 里收录便于跨笔记跳转）
