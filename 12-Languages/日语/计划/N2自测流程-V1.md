# 📝 JLPT N2 诊断性自测流程

> **目的**：定位真实薄弱点，指导 Phase 1 学习重点
> **原则**：这是诊断，不是考试。分数不重要，知道哪里需要补才重要。

---

## 📦 前置准备

### 1. 确认数据来源

| 模块 | 抽样/测试方式 |
|------|---------------|
| 文法 | 从 `语法/00 索引.md` 的 N2 部分随机抽 30 条 |
| 词汇 | 把现有的笔记全部过一遍,边过边补缺 |
| 汉字 | 真题抽样 20 题 |
| 读解 | 真题 4 篇 |
| 聴解 | 真题 10 题 |

> 笔记数量随时变动,不在此处写死。抽样时按笔记本身决定,缺多少心里有数即可。

### 2. 准备工具

```bash
# 打开这些文件备用
- 日语/语法/00 索引.md      # 文法抽样用
- 日语/单词/副詞/00 索引.md  # 词汇抽样用
- 日语/单词/形容詞/00 索引.md
- DeepTutor (:3782)         # 解析追问用
- 计时器（手机）
```

## 🔬 第一步：文法自测（30 分钟）

### 抽样方法

从 `语法/00 索引.md` 的 N2 部分（约 50 条）随机抽 30 条：

```
1. 滚动到 N2 语法区域
2. 闭眼指一个，作为起点
3. 向前取 15 条，向后取 15 条
4. 共 30 条
```

### 测试方式

对每条语法：
1. **遮住**右边的解释
2. 凭记忆写出：
   - 接续规则（前面接什么形）
   - 核心作用（表示什么含义）
   - 造 1 个例句
3. **对照**笔记检查，标记 ✓ / ✗

### 记录格式

```markdown
## 文法自测结果

**得分**：___/30 (___%)

**错误分布**：
- 接续错误：__ 题
- 作用理解偏差：__ 题
- 完全遗忘：__ 题

**薄弱语法点**（标记为 🔴 需重点复习）：
1. [语法点1] — _（问题：接续记混/作用理解偏差）_
2. [语法点2] — _（问题：完全遗忘）_
3. ...
```

---

## 🔬 第二步：词汇自测（20 分钟）

### A. 笔记覆盖测试（15 分钟）

从索引中抽取：
- 副詞：15 条（从 `单词/副詞/00 索引.md`）
- 形容詞：15 条（从 `单词/形容詞/00 索引.md`）

**测试方式**：
1. 遮住笔记内容
2. 看词条，凭记忆写出：
   - 读音（假名）
   - 核心意思
   - 1 个固定搭配
3. 对照检查，标记 ✓ / ✗

### B. Anki 交叉验证（5 分钟）

```
1. 打开 Anki
2. 复习最近 7 天新建的卡片
3. 记录：
   - 复习数量：__ 张
   - 正确数量：__ 张
   - 遗忘率：__%
```

### 记录格式

```markdown
## 词汇自测结果

**笔记测试得分**：___/30 (___%)

**按词类拆分**：
- 副詞：___/15
- 形容詞：___/15

**Anki 复习**：
- 复习数量：__ 张
- 遗忘率：__%

**薄弱词汇类型**（标记为 🔴）：
- [ ] 副词混淆（如「むしろ/わりと」辨析不清）
- [ ] 形容词同音字（如「暖かい/温かい」）
- [ ] 惯用语不懂
- [ ] Anki 新卡遗忘率高
```

## 🔬 第三步：汉字自测（15 分钟）

**来源**：真题「文字・词汇」section

```
1. 打开过去问卷
2. 做汉字读音题（约 10 题）
3. 做汉字用法题（约 10 题）
4. 计时，对答案
```

### 记录格式

```markdown
## 汉字自测结果

**得分**：___/20 (___%)

**薄弱点**：
- [ ] 音读/训读混淆
- [ ] 同音字分不清
- [ ] 汉字用法（如「する」搭配）
- [ ] 新出汉字不认识
```

---

## 🔬 第四步：读解自测（35 分钟）

**来源**：真题「読解」section

```
1. 做 4 篇短文理解（A1+A2+B+C）
2. 严格计时 35 分钟
3. 对答案，记录每篇耗时
```

### 记录格式

```markdown
## 读解自测结果

**得分**：___/40 (___%)

**各篇得分**：
| 篇目 | 得分 | 满分 | 耗时 |
|------|------|------|------|
| A1（ short passage）| | 10 | min |
| A2（ short passage）| | 10 | min |
| B（ medium passage）| | 10 | min |
| C（ long passage）| | 10 | min |

**薄弱题型**（标记为 🔴）：
- [ ] 主旨题总错
- [ ] 细节题超时
- [ ] 指代题理解偏差
- [ ] 作者意图推断错误
```

---

## 🔬 第五步：聴解自测（25 分钟）

**来源**：真题「聴解」section

```
1. 做 10 道听力题
2. 严格按考试流程（播放→答题→收卷）
3. 注意：N2 听力只放一遍！
```

### 记录格式

```markdown
## 聴解自测结果

**得分**：___/30 (___%)

**薄弱题型**（标记为 🔴）：
- [ ] 即时应答反应慢
- [ ] 长对话抓不住重点
- [ ] 图理解题错得多
- [ ] 总结题理解偏差
- [ ] 听力速度跟不上
```
