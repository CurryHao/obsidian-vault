# JLPT N2 备考规划（2026-08 → 2028-07）

> 核心结论：**你语法已领先，真正的战场是单词 + 读解 + 听解。** 未来 24 个月的主线不是「学更多语法」，而是把词汇量补齐、把输入（阅读/听力）养成每日习惯、用真题把四块捏成考试能力。

## 一、现状诊断（基于 2026-08-27 实际库内容）

| 模块 | 状态 | 证据 |
|------|------|------|
| 文法（语法） | ✅ 超前 | ~190 条语法笔记；索引 N2 应试语法 ~50+ 项已建；Anki 193 张语法卡已导入 |
| 単語（词汇） | ⚠️ 刚起步 | 47 张副词笔记；N2 名词/动词/形容词/惯用语/近义辨析词条为空（索引勾选为装饰） |
| 漢字（汉字） | ❓ 未跟踪 | 库中无汉字专项笔记，需另行建跟踪 |
| 読解（阅读） | ❌ 空白 | 库内无任何阅读/读解材料 |
| 聴解（听力） | ❌ 空白 | 库内无任何听力材料 |
| Anki 单词卡 | ❌ 缺失 | 记忆记录仅语法卡导入；单词笔记尚未进 Anki |
| 学习日志 | ⚠️ 断更 | 仅 2 篇（8/20、8/26），累计 150 min |

**最大风险**：语法完成度高但词汇/输入薄弱 → 读解题读不懂、听力跟不上。N2 文字語彙+文法+読解+聴解四块中你只扎实了文法，而读解+聴解占分近 2/3。

## 二、总目标与时间线

- **总周期**：约 24 个月（2026-08 → 2028-07）
- **词汇目标**：累计 ~6000 词（N2 要求），当前约为个位数百分比，需系统性补齐
- **汉字目标**：N2 累计 ~1000 汉字（在 N3 基础上新增约 350）
- **输入目标**：能流畅读 NHK News Web Easy → 过渡至 N2 真题长文；听力能跟住 N2 语速对话/独白
- **节奏**：工作日 ~45–60 min，周末 ~2 hr，合计 ~9 hr/周；24 个月 ≈ 900 hr（N2 典型需求 600–900 hr，窗口充足）

## 三、四阶段路线图

### Phase 0 — 系统搭建与诊断（现在 → 2 周）
- [ ] 做一次诊断：拿一份往年 N2 真题的「文法+词汇」section 自测，定位真实薄弱点（验证「语法强/词汇弱」假设）
- [ ] 确定并采购教材（见第五节），建立 `計画/` 与 `単語/`、`読解/`、`聴解/` 子目录
- [ ] **把现有 47 张单词笔记批量导入 Anki**（现有 Anki MCP 建卡有 JSON bug，需用 curl 直连，见附录）
- [ ] 重建每日日志习惯：哪怕 1 行，用现有 `日志/00 索引.md` 模板

### Phase 1 — 建设期：补词汇 + 养输入（2026-09 → 2027-05，约 9 个月）
- 文法：用《新完全マスター 文法 N2》做一遍完整梳理，填补笔记遗漏项（接续词、高级表达等未勾选项），保持 Anki 语法卡复习
- 単語：系统推进 N2 词汇（名词/动词/形容词/慣用句/近義語），笔记→Anki 卡流水线每日运转，目标 Phase 末累计接近 N2 要求量
- 漢字：《新完全マスター 漢字 N2》按课推进，建汉字跟踪表
- 読解：每日 NHK News Web Easy 1 篇（~15 min），从「读得懂」过渡到「读得快」
- 聴解：每日 15–30 min 听力输入（播客/慢速日语），先磨耳朵不急着做题
- **里程碑**：Phase 末能轻松读 NHK Easy，词汇卡稳定日复习，听力能抓大意

### Phase 2 — 整合期：分块真题化（2027-06 → 2028-02，约 9 个月）
- 読解：《新完全マスター 読解 N2》+ 计时训练
- 聴解：《新完全マスター 聴解 N2》系统刷
- 文法/単語：转入「维护模式」——靠 Anki 复习 + 从真题错题反查薄弱点精准补漏
- **每月 1 套计时模考**（从本阶段起），记录分数，定位波动模块

### Phase 3 — 冲刺期：模考 + 弱点歼灭（2028-03 → 2028-07，约 5 个月）
- 每 2 周 1 套全真模考（官方問題集/過去問），严格计时
- 建立「错题→知识点」回溯表，集中歼灭反复错的点
- 最后 1 个月降强度、保状态、过一遍高频考点与惯用语
- **考试：2028-07**

## 四、每周节奏模板（贴合你的 Obsidian+Anki+日志习惯）

| 时段 | 内容 | 时长 |
|------|------|------|
| 工作日 Mon/Wed/Fri | Anki 复习（语法+词汇，不可省）+ 新语法/词汇笔记 | 45–60 min |
| 工作日 Tue/Thu | Anki 复习 + NHK Easy 阅读 1 篇 | 45–60 min |
| 周六 | 听力块（播客 + 聴解 drills）+ Anki | ~60 min |
| 周日 | 周复盘 + 1 个模考 section 或弱点专项 + 写日志 | ~60 min |
| 每月 | 1 套完整计时模考（Phase 2 起） | 半天 |

> 原则：**Anki 每日复习是非协商项**；新内容量小但每日持续，胜过周末突击。日志哪怕一行也要写，它是计划不漂移的反馈环。
