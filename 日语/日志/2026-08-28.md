## 核心活用表（复习）

### な形容词（靠「です」承担活用）
| 形式 | 静か |
| --- | --- |
| 肯定现在 | 静か**です** |
| 否定现在 | 静か**ではありません** |
| 肯定过去 | 静か**でした** |
| 否定过去 | 静か**ではありませんでした** |
| 修饰名词 | 静か**な**部屋 |

### い形容词（词尾「い」自己变）
| 形式 | 高い |
| --- | --- |
| 肯定现在 | 高**い** |
| 否定现在 | 高**くない** |
| 肯定过去 | 高**かった** |
| 否定过去 | 高**くなかった** |
| て形 | 高**くて** |

### 动词ます形与て形
| 动词类型 | ます形 | て形 | 例 |
| --- | --- | --- | --- |
| 五段 | 词尾う段→い段 + ます | 有音便（待学） | 書く → 書**きます** |
| 一段 | 去る + ます | 去る + て | 食べる → 食べ**ます** / 食べ**て** |
| カ变 | 来（き）ます | 来（き）て | 来る → **来ます** / **来て**（读「きて」） |
| サ变 | します | して | する → **します** / **して** |

### ます形活用
| 形式 | 食べる（礼貌体） |
| --- | --- |
| 肯定现在 | 食べ**ます** |
| 肯定过去 | 食べ**ました** |
| 否定现在 | 食べ**ません** |
| 否定过去 | 食べ**ませんでした** |

## 难点/错题
- い形容词否定误用な形容词系统：~~高いではありません~~ ✗ → 高**くない** ✓
- 判断い/な形容词的唯一标准：**接名词加不加「な」**（きれい・嫌い 虽以「い」结尾，但是な形容词）
- カ变「来る」的て形写作「**来て**」，读作「**きて**」（非「こて」）
- 动词分类判断口诀：来る/する→カ/サ变；不以「る」结尾→五段；以「る」结尾看前面假名（い/え段→一般一段，あ/う/お段→五段）

### 第 7 题｜副词辨析：ゆっくり vs 静かに
- 题目：もう少し（　）話してください。
- 我的答案：静かに ✗
- 正确答案：**ゆっくり** ✓
- 辨析：
  - **ゆっくり話す** = 放慢语速说 → 与「もう少し」搭配，表示"请再说慢一点"。
  - **静かに話す** = 小声/安静地说 → 侧重**音量**，不是语速。
  - 同组词：「早く」（快）、「大きく」（大声），考查的是"语速 / 音量"两个维度的词义区分。

### 第 9 题｜句型：～ば～ほど
- 题目：日本語を勉強すればする（　）、上手になります。
- 我的答案：から ✗
- 正确答案：**ほど** ✓
- 语法点：「～ば～ほど」＝ 越……越……，前项程度加深，后项随之变化。
- 接续：勉強すれば勉強するほど ＝ 勉強すればするほど
- 关联：[[日语/语法/2026-08-21-ば～ほど]]

### 第 12 题｜动词可能形 vs 被动形
- 题目：動詞「読む」の可能形はどれですか。
- 我的答案：読まれる ✗（这是被动形）
- 正确答案：**読める** ✓
- 语法点：五段动词可能形 ＝ 词尾「う段」→「え段」＋ る。
  - 読む → 読め＋る → **読める**
  - 对比：読ま**れる** = 被动形；読ま**せる** = 使役形
- 易混点：可能形（読める）、被动形（読まれる）、使役形（読ませる）三者尾缀要分开记。
