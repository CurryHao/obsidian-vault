# 语法：～さえ～ば

## 接续
- 动词ます形（去掉ます）+ さえ + すれば / しなければ
- イ形容词词干 + く + さえ + あれば / なければ
- ナ形容词词干 + で + さえ + あれば / なければ
- 名词 + で + さえ + あれば / なければ
- 正确示例：この薬を飲みさえすれば、暇さえあれば
- 错误示例：この薬を飲むさえすれば、暇さえあるば

## 核心用法详解

### 限定唯一最低必要条件
只要满足这一个最基础条件，其他所有条件都不重要，后项结果一定成立。

典型例句：
- この薬を飲みさえすれば、すぐ治れると思います。——只要喝这个药马上就好
- 子供がもう少し大きくさえあれば、私も仕事が始められるのに。——只要孩子再大一点我就能工作
- 静かでさえあれば、狭くてもいい。——只要安静房子小点也没关系
- 金属でさえあればいい。——只要是金属就行

## 注意
- 和普通「～ば」区别：后者单纯描述条件结果对应，前者叠加排他强调"唯一必要条件"
- 接续错误：不能接动词原形、イ形容词连体形
- 语义误用：不用于需要多个条件共同满足的场景
