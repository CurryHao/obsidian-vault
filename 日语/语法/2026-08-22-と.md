# 语法：～と

## 接续
- 动词/い形容词简体形 + と
- な形容词词干 + だ + と
- 名词 + だ + と

典型例句：
- 春になる**と**、花が咲く — 一到春天，花就开
- 雨が降る**と**、道が濡れる — 一下雨，路就湿
- 痛い**と**、体が硬くなる — 疼的话，身体会变僵硬
- 静か**だと**、落ち着く — 安静的话，很安稳
- 学生**だと**、割引がある — 是学生的话，有折扣

## 核心用法详解

### 用法一：恒常条件（一……就……）
语义：描述自然规律、常识、长期固定习惯。前项成立，后项必然发生，没有例外。

典型例句：
- 春になると、青い芽が出る — 一到春天，就会长出绿芽
- 6を3で割ると2になる — 6除以3等于2

避坑提示：此用法与「ば」可互换，但「と」强调更强的客观必然性，不带主观推断语气。

### 用法二：确定顺接条件（刚做完A，紧接着发生B）
语义：两个动作几乎无缝衔接，前项完成的瞬间立刻触发后项结果。

典型例句：
- 家に帰ると、日が暮れた — 刚回到家，天就黑了
- 道を右に曲ると、駅が見えた — 向右一拐，就看到车站了

避坑提示：此用法强调时间上的紧密衔接，类似中文"一……就……"。

### 用法三：假定顺接条件（一旦……就会……）
语义：强调前项一旦成立，后项必然会出现对应结果，强调整体必然性。

典型例句：
- 長い間本を読むと、目が疲れる — 长时间看书的话，眼睛就会累
- 雨が降ると、道が濡れる — 一下雨，路就会变湿

### 用法四：提示话题/范围（说到……的话）
语义：以某个内容为切入点，引出后续的判断或说明。

典型例句：
- 結果を示すと、次の通りです — 展示结果的话，如下所示
- 君の考えだと、後で問題が起こりそうだ — 按照你的想法，之后大概率会出问题

避坑提示：此用法中「だと」是「だ」+「と」的缩略形式，实际是「であることだと」的口语简化。

## 注意
- **核心禁忌：后句绝对不能接意志、命令、推测、建议类表达**
  - × ご飯を食べると、散歩に行きましょう（错误，后句为意志邀约）
  - ○ ご飯を食べたら、散歩に行きましょう（正确，用たら承接意志）
- 所有成分必须使用简体形，不能直接接敬体形（这是基础阶段高频易错点）
- 「と」与「たら」的最大区别：「と」后句只能是客观结果或自然现象，不可接人的意志性行为
- 「Aとなる」表"逐渐变成某种状态"，如「雨は夜に入って雪となった」（入夜后雨变成了雪）
- 听力中，操作流程说明、自然常识科普类对话里，「～と」是核心逻辑连接词
