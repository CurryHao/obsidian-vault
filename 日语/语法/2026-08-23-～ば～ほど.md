# 语法：～ば～ほど

## 一、基础接续规则
动词：动词假定形（ば形） + 同一动词辞书形 + ほど
イ形容词：イ形容词假定形（～ければ） + 同一イ形容词辞书形 + ほど
ナ形容词：ナ形容词假定形（～なら/であれば） + 同一ナ形容词词干 + な + ほど
名词：名词假定形（～なら/であれば） + 同一名词 + である + ほど
简化规则：前后重复的部分可以省略，比如「練習すればするほど」可简化为「練習すればほど」

## 二、核心语义
表示随着前项事物的程度不断提高，后项的程度也会随之同比增长，是典型的正比递进逻辑，完全对应中文“越…越…”的语义。

## 三、典型例句
練習すればするほど上手になります。（越练习就会越进步）
給料は高ければ高いほどいいです！（工资越高越好啊！）
歯の治療は早ければ早いほどいい。（牙齿的治疗越早越好）
有名人であればあるほどストレスも大きいのではないだろう。（人不是越有名越累吗？）

## 四、高频避坑要点
前后必须使用同一个词类的同源表达，不能跨词性混搭
不能用于描述完全没有逻辑关联的两个事物，必须满足“前项程度提升带动后项同步变化”的正比逻辑
口语中常省略「ば」直接用「～ほど」表达，语义完全等价，比如「読めば読むほど」可简化为「読むほど」
该语法没有否定形式，不能直接接否定含义的后项内容
