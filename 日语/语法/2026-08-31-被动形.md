# 语法：被动形/受身形（あ段＋れる・られる）

## 接续

被动形本质是「动词辞书形 → 表达被动的活用」。三大类别规则：

| 类别 | 变形规则 | 例 |
|------|---------|----|
| 一类（五段）动词 | 词尾假名变成对应**あ段**假名 + れる | 殴る → 殴**られる**、待つ → 待**たれる**、呼ぶ → 呼**ばれる**、言う → 言**われる** |
| 二类（一段）动词 | 去掉词尾「る」+ **られる** | 褒める → 褒**められる**、食べる → 食**べられる**、見る → 見**られる** |
| 三类动词 | する → **される**、来る → **来（こ）られる** | 勉強する → 勉強**される**、来る → 来**られる** |

礼貌体后续「ます／ました／ません／ました」等礼貌助动词：

| 时态/语气 | 形态 |
|-----------|------|
| 现在时礼貌体 | 殴**られます**／褒**められます**／勉強**されます** |
| 过去时礼貌体 | 殴**られました**／褒**められました**／勉強**されました** |
| 否定礼貌体 | 殴**られません**／褒**められません**／勉強**されません** |
| た形（接续用） | 殴**られた**／褒**められた**／勉強**された** |

施动者用「**に**」提示（被动句里"被谁"用「に」），对象用「**を**」保留（与原他动词用法一致）。

## 核心用法详解

### 直接被动（标准被动）

主动句的**宾语**直接变成被动句的**主语**，是中文被动逻辑最接近的常规用法。结构：

```
主动：X が Y を V（他动词）
被动：Y が X に V-られる（主语是原宾语 Y，施动者是原主语 X）
```

典型例句：
- 先生**に**叱**られた** — 被老师批评了
- 友達**に**褒**められた** — 被朋友表扬了
- 部長**に**呼**ばれた** — 被部长叫了
- 母**に**起こ**された** — 被妈妈叫醒了

适用场景：客观描述某人被施加某个动作，**主语是人或动物**。

### 间接被动（受害被动／迷惑受身）

日语独有的特殊用法，**中文没有完全对应的表达**。主动句里原本**不存在的主语**，因为他人的动作间接受到了损害、造成了困扰。施动者用「に」，主语往往是"我"，**不出现「を」宾语**（因为原主动句里根本没有动作施加到这个主语上，是日语特有的"被波及"语义）。

典型例句：
- 雨**に**降**られた** — 被雨淋了（暗指"被雨浇得很倒霉"，强调我的不幸）
- 電車で隣の人**に**足**を**踏**まれた** — 在电车上被旁边的人踩了脚
- 隣の部屋**に**夜中**に**うるさく**された** — 被隔壁房间半夜吵到
- 彼女**に**泣**かれた** — 被她（突然）哭，搞得我很难办

避坑提示：**这种结构必须带"受害、不幸、无奈"的负面语气**，没有负面语感的语境不应用。日语母语者说「雨に降られた」自带"我真倒霉"的语感。

### 物主被动（间接被动的高频子类）

专门描述「**主语的所属物品被他人施加动作，主语本人连带受到了影响**」。结构上保留「を」宾语（指向所属物），但主语一定是物主本人，因此**物主也被波及受害**。

```
主动：誰かが 私の財布を 盗む
被动：私 は 泥棒に 財布 を 盗まれた（我是物主，財布是所属物，我受害）
```

典型例句：
- 私**は**泥棒**に**財布**を**盗**まれた** — 我的钱包被小偷偷了（我因此受害）
- 私**は**母**に**彼氏**と**別れ**させられた**（≈ 私 は母に彼氏と別れさせられた）— 我被妈妈逼着和男朋友分手了
- 田中さん**は**同僚**に**プレゼン**を**邪魔**された** — 田中的presentation被同事搅黄了

中文直译会显得很别扭（"我的钱包被小偷偷了"听起来像反复强调物主），但日语母语者日常使用频率极高，是 N3 写作必学表达。

### 客观叙述类被动（中性语感）

用于新闻、说明书、广告里的**客观状态描述**，动作的施动者**完全不明确、不需要特意点明**，**主语是事物**。这是少数日语被动形**不带受害语感**的中性场景。

典型例句：
- 駅前**に**高いビル**が**建**てられた** — 车站前建起了高楼（不强调谁建的）
- この橋**は**1920年**に**作**られた** — 这座桥建于 1920 年
- ここ**で**映画**が**撮**られた** — 这里拍过电影
- 新しいルール**が**決**められた** — 决定了新规则

避坑提示：**这种客观叙述被动**不点施动者（无「に」），不带负面语感——是日语被动形**唯一中性**的语境。

## 注意

### 二类动词：被动形与可能形完全同形（核心考点）

二类动词的被动形和可能形长得**完全一样**（都是「られる」），这是 JLPT N4-N3 高频出题陷阱：

| 形态 | 助词提示 | 含义 | 例 |
|------|---------|------|----|
| パン**が**食**べられる** | 用「が」提示对象 | 能吃（可能形） | パン**が**食べられる → 能吃面包 |
| パン**を**犬**に**食**べられた** | 用「に」提示施动者 | 被吃（被动形） | パンを犬に食べられた → 面包被狗吃了 |

区分技巧：
- **用「が」提示对象** → 大概率是**可能形**（可能形自身用「が」替换「を」，详见 [[可能形]]）
- **用「に」提示施动者** → 一定是**被动形**（被动形的施动者固定用「に」）

例：
- 私**は**日本語**が**話せる（我会说日语 / 可能形）
- 私**は**先生**に**褒められた（我被老师表扬了 / 被动形）

### 中文被动 vs 日语被动：核心语感差异

中文被动大多只表**客观动作被施加**，日语被动绝大多数场景下都自带「**受害、无奈、不幸**」的负面语感：

| 语境 | 中文翻译 | 日语语感 |
|------|---------|---------|
| 老师批评我 | 我被老师批评了（中性） | 先生**に**叱**られた**（带"我真可怜"的语感） |
| 朋友表扬我 | 我被朋友表扬了（中性） | 友達**に**褒**められた**（带"我很高兴/意外"的语感） |
| 被雨淋了 | 我被雨淋了（中性偏倒霉） | 雨**に**降**られた**（强烈"我真倒霉"语感） |

**只有客观叙述类的物做主语被动句是中性的**（见上文第 4 节），其他所有"人被施加动作"的被动句都自带或强或弱的负面／主观色彩。

### 主动句里带「を」的物主被动 vs 直接被动

两者的核心区分：**主语是不是所属物的物主**。

| 类型 | 结构 | 主语角色 |
|------|------|---------|
| 直接被动 | X が V-られる（不带「を」） | 主语就是动作承受者本人 |
| 物主被动 | X は 誰かに 自分の物 を V-られる | 主语是物主，所属物被施加动作 |

### 高频易错点

**1. 被动形不能用于自发的动作承受者**

不是所有"被施加"的动作都用被动。日语母语者很少说"我被风吹"这种程度的物理现象（除非特别强调受害），自然现象的描述用普通句：

- ✗ 風**に**吹**かれた**（错例：用被动形显得太严重）
- ○ 風が吹いた（自然描述）
- 特殊情况（强调"我真倒霉"）：台風**に**吹**かれて**家が壊れた（被台风刮得房子都坏了）

**2. 间接被动的「に」不能换成「から」或「によって」**

- ○ 雨**に**降られた（标准）
- ✗ 雨**から**降られた（错例）
- ✗ 雨**によって**降られた（错例，用于书面正式被动，「に」也可以）

**3. 主动句里没有的动作承受者，不能用直接被动**

直接被动要求主动句里**存在原宾语**。如果主动句里根本没有某个对象被动作施加，硬套被动结构会出错：

- ✗ 私**が**友達**に**行**かれた**（错误：行かない，不是他动词）
- ○ 友達**に**先**に行かれた**（朋友先走了，我被抢先 / "先に行かれる"是合法结构）
