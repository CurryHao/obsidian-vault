# 语法：～てしかたがない

## 一、基础接续规则
动词‌：动词て形 + も + しかたがない
イ形容词‌：イ形容词词干 + くて + も + しかたがない
ナ形容词‌：ナ形容词词干 + で + も + しかたがない
名词‌：名词 + で + も + しかたがない
「しようがない」「しょうがない」是「しかたがない」的口语变体，语义完全一致

## 二、核心语义说明
表示无论做出什么努力，都无法改变当前的既定状况，只能被动接受这个无可奈何的现实
隐含“努力是徒劳的、没必要继续纠结”的潜台词，用来劝慰他人或自我开解

## 三、典型实用例句
後悔してもしょうがない。次はもっと気をつけよう：后悔也没用，下次多注意一点吧
どんなに説明してもしかたがない。彼は聞く耳を持たないんだから：无论怎么解释都没用，他根本听不进去
寒くてもしょうがない。暖房が故障しているから：冷也没办法，暖气坏了
今更文句を言ってもしかたがない：事到如今发牢骚也没用

## 四、和「～てしかたがない」的核心区别
「～てしかたがない」：没有「も」，语义是“……得不得了”，用来描述强烈的情绪、生理感受
「～てもしかたがない」：带「も」，语义是“即使……也没用”，属于逆接条件句型，完全不表程度含义

## 五、口语变体
口语中「～たって」是「～ても」的缩略形式，因此衍生出「～たってしょうがない」的更随意的口语表达，日常对话中使用频率很高
