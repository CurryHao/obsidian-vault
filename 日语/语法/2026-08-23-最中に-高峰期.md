# 语法：～最中に

## 接续
- 动词持续体（ている形） + 最中に
- 名词 + の + 最中に
- 正确示例：電話している最中に、会議の最中に
- 错误示例：電話する最中に、会議最中に

## 核心用法详解

### 动作高峰期突然被打断
强调动作正处于100%进行的高峰期，突然发生意外打断事件。

典型例句：
- ご飯を食べている最中に、友達が突然訪ねてきた。——正吃着饭朋友突然来访
- 試合の最中に突然雨が降り出した。——比赛正进行到一半突然下雨

## 注意
- 和「～途中で」区别：最中は动作最投入的核心阶段，途中是任意节点不强调投入状态
- 和「～ところを」区别：最中仅描述持续进行，ところ覆盖刚要开始/进行中/即将结束
- 接续错误：不能接动词原形，名词后遗漏「の」
- 语义误用：不用于已结束的动作
