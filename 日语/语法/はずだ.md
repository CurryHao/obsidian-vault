# 文法：はずだ／はずがない

## 接続
- 動詞（简体形）+ はずだ／はずがない
- イ形容詞（简体形）+ はずだ／はずがない
- ナ形容詞（词干）+ な + はずだ／はずがない
- 名詞 + の + はずだ／はずがない

**核心前提：** 所有接续都必须使用简体形，不能直接接敬体形。

## コア概念

基于逻辑推理的核心推量句型，分为完全对立的正反对立表达组合。「はずだ」表正向预期（理应如此）、「はずがない」表强烈否定（不可能）。

---

## 用法一：はずだ（理应如此）

核心语义：基于已有的常识、已知线索进行逻辑推导，得出「理应如此、应该会这样」的正向预期，不是凭空猜测。

典型例句：
- 彼は昨日東京に行ったから、今日はここにいないはずだ。——他昨天去了东京，今天理应不在这儿。
- この本はとても有名だから、誰でも知っているはずだ。——这本书非常有名，按理来说所有人都应该知道。
- 毎日練習しているんだから、上手くなるはずだ。——每天都在练习，应该会变强的。
- 約束したんだから、来るはずだ。——既然约好了，应该会来的。
- 彼女は医者だと聞いたから、詳しいはずだ。——听说她是医生，应该很懂行的。

结构特征：
- 前项提供已知线索（から/なので/ている等）
- 后项进行逻辑推导（はずだ）
- 推导结果具有较高确定性

---

## 用法二：はずがない（不可能）

核心语义：基于逻辑和已知事实，彻底否定某件事发生的可能性，语气非常强烈，中文译为「不可能、绝不会」。

典型例句：
- 彼は昨日熱が40度もあったから、今日試合に出られるはずがない。——他昨天烧到40度，今天绝对不可能上场比赛。
- そんな難しい問題が小学生に解けるはずがない。——那么难的题，小学生根本不可能解出来。
- 彼がそんなことを言うはずがない。——他不可能说那种话。
- 雨降っているのに、外が乾いているはずがない。——下着雨，外面不可能干的。
- 一生懸命勉強したのに、不合格なはずがない。——拼命学习了，不可能不合格的。（反向推导：理应合格）

结构特征：
- 前项提供已知线索（从/ので/ている等）
- 后项进行逻辑否定（はずがない）
- 否定语气非常强烈，几乎100%排除可能性

---

## 高频考点辨析

### ① はずだ vs ようだ

| | はずだ | ようだ |
|---|---|---|
| 推理基础 | 基于逻辑推理，有明确的已知线索支撑 | 基于感官观察，没有严谨的逻辑推导过程 |
| 确定性 | 较高，预期「理应如此」 | 较低，表「看起来……」 |
| 示例 | 彼は医者だ。だから詳しいはずだ。——他是医生，所以应该很懂行。（逻辑推导） | 彼は医者だ。詳しいようだ。——他好像是医生，看起来很懂行。（观察推测） |
| 示例 | 雨が降った。地面が濡れているはずだ。——下雨了，地面理应湿的。（线索→推导） | 地面が濡れている。雨が降ったようだ。——地面湿了，好像下雨了。（观察→推测） |

关键区别：
- 「はずだ」= 有依据的逻辑推导，确定性强
- 「ようだ」= 基于感官的模糊推测，确定性弱

---

### ② はずがない vs わけがない

| | はずがない | わけがない |
|---|---|---|
| 语义 | 几乎完全等价，表「不可能」 | 几乎完全等价，表「不可能」 |
| 侧重 | 更侧重基于过往经验的否定 | 更侧重基于客观道理的否定 |
| 语气 | 强烈 | 强烈 |
| 示例 | 彼が行くはずがない。——他不可能去。（基于经验判断） | 彼が行くわけがない。——他不可能去。（基于道理判断） |

注意：二者在日常场景中几乎可以互换，但在严谨的逻辑推理中：
- 经验性否定多用「はずがない」
- 客观道理性否定多用「わけがない」

---

### ③ 来るはずがない vs 来ないはずだ

| | 来るはずがない | 来ないはずだ |
|---|---|---|
| 结构 | 肯定动词 + 否定推量 | 否定动词 + 肯定推量 |
| 语义 | 否定「他会来」这个预期，表「根本不可能来」 | 直接推导得出「他不会来」的正向预期，表「按理来说他不会来」 |
| 语气 | 强烈否定（不可能） | 温和推量（应该不会） |
| 示例 | 彼が来るはずがない。——他不可能来。（完全否定可能性） | 彼が来ないはずだ。——他应该不会来。（推导出不来） |

关键区别：
- 「来るはずがない」= 强调「来」这件事不可能发生
- 「来ないはずだ」= 强调「不来」是合理推断的结果

## 注意

### 接续要点
1. **必须使用简体形**，不能接敬体形
   - × 行くはずです（错误）
   - ○ 行くはずだ（正确）
   - × 行かないはずです（错误）
   - ○ 行かないはずだ（正确）

2. **名词/な形容词接续规则**
   - 名詞 + の + はずだ：学生のはずだ（应该是学生）
   - ナ形容詞 + な + はずだ：安心なはずだ（应该放心）

3. **口语缩略形式**
   - 口语中常缩略为「はずない」
   - 例：そんなことあるはずない。——不可能有这种事。

### 考试易错点
1. **70%的考点集中在「はずがない」的强烈否定语义**，经常和「わけがない」「べきではない」等选项组合考察
2. **「はずだ」不能用于描述自己主动做出的动作**
   - × 私は行くはずだ。（错误，不能用于自己主动的行为）
   - ○ 私は行くつもりだ。（正确，打算去）
3. **必须区分「来るはずがない」和「来ないはずだ」**
   - 前者是完全否定可能性
   - 后者是基于线索的合理推断
4. **不能用于凭空猜测**
   - × 明日雨が降るはずだ。（无依据的猜测）
   - ○ 明日雲が多いから、雨が降るはずだ。（有依据的推导）
