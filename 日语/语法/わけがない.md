# 文法：～わけがない

## 接続
- 名詞 + な/である + わけがない
- 動詞普通形 + わけがない
- い形容詞普通形 + わけがない
- な形容詞普通形 + わけがない
- 口語音便：「わけない」（より随意・強烈）

## 核心的な用法

### 常识・論理に基づく絶対的な否定
客観的事実や普遍的道理から「そのようなことが起こる道理がない」と完全に否定する。

典型例文：
- まじめな彼が嘘をつくわけがない — 认真的他不可能说谎
- 氷が熱いわけがない — 冰不可能是热的（违反物理常识）
- 努力しなくて成功するわけがない — 不努力，不可能成功

### 事実・証拠に基づく断然的否定
既に知られている事実から、特定の変化や事態の成立を強く否定する。

典型例文：
- さっきまであったんだから、消えるわけがないよ！ — 刚才还在，所以绝不可能消失！
- こんな複雑な問題が簡単に解けるわけがないじゃないか — 这么复杂的问题，怎么可能轻易解得开呢？

## 注意

### 「～わけがない」vs「～ないはずだ」
- **わけがない**：普遍的道理・客観的逻辑から「ありえない」と断じる。**语气强硬、不留余地**。
  - 例：氷が熱いわけがない。（冰不可能是热的。→ 违反物理常识）
- **ないはずだ**：具体の証拠・已知の情報から合理的に推測する否定。**语气较客观、留有探讨余地**。
  - 例：彼は約束を守る人だから、来ないはずがない。（他是个守约的人，应该不会不来。→ 基于对其为人的了解做出的合理推测，但理论上仍有意外可能）

### 「～わけがない」vs「～ようがない」（既学済み）
- **わけがない**：可能性や合理性を否定。「不可能发生」。
- **ようがない**：方法や手段の不存在を否定。「没办法做」。

対照例：
- そんな嘘、信じるわけがない。（那种谎话，不可能相信。→ 情理上根本不会去信）
- 証拠がなくて、信じようがない。（什么证据都没有，无法相信。→ 想相信，但缺乏相信的途径或依据）

### 口语音便
- 「わけがない」→ 「わけない」（口语中常见，语气更强烈随意）
- 例：彼が知ってるわけないよ！（他不可能知道啦！）
