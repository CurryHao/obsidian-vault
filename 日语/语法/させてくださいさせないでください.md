# 语法：させてください／させないでください

## 接续

### 肯定形「～（さ）せてください」
动词先变为使役形，后续直接接「てください」

| 动词类型 | 变形规则 | 示例 |
|----------|----------|------|
| 五段动词 | 未然形 + させる → させ + てください | 行く → 行かせる → 行かせてください |
| 一段动词 | 去掉る + させる → させ + てください | 食べる → 食べさせる → 食べさせてください |
| サ变动词 | する → させる → させてください | する → させる → させてください |
| カ变动词 | 来る → 来させる → 来させてください | 来る → 来させる → 来させてください |

### 否定形「～（さ）せないでください」
动词使役形的ない形后续接「でください」

| 动词类型 | 变形规则 | 示例 |
|----------|----------|------|
| 五段动词 | 未然形 + させない → させないでください | 騒ぐ → 騒がせる → 騒がせないでください |
| 一段动词 | 去掉る + させない → させないでください | 食べる → 食べさせる → 食べさせないでください |
| サ变动词 | する → させない → させないでください | する → させない → させないでください |
| カ变动词 | 来る → 来させない → 来させないでください | 来る → 来させない → 来させないでください |

## 核心语义与用法

### 肯定形核心含义
请求对方允许自己做某事，中文译为"请让我做……"，是初级阶段最基础的使役请求句型。

典型例句：
- 私に一言喋らせてください。 — 请让我说几句。
- この問題を説明させてください。 — 请让我解释这个问题。
- ちょっと確認させてください。 — 请让我确认一下。

### 否定形核心含义
请求对方不要让自己做某事，中文译为"请不要让我……"，用来委婉拒绝对方的安排。

典型例句：
- そんな難しい仕事を私にやらせないでください。 — 请不要让我做这么难的工作。
- 私にそんなことを言わせないでください。 — 请不要让我说那种话。
- 彼に知らせないでください。 — 请不要让他知道。

## 语气特征与使用边界

该句型自带轻微的命令语气，对上司、年长者直接使用会显得不够谦恭，正式敬语场景下通常替换为更礼貌的「～（さ）せていただけますか」。

仅在自告奋勇、态度极其坚决的特殊场景下，对长辈使用该句型才不会失礼，比如紧急情况下主动请缨承担任务。

## 注意

### 高频考点与避坑规则
1. **绝对不能把使役形和可能形搞混**：该句型的核心前提是先正确完成动词使役形变形。
   - 错误：～ていただけ（可能形）
   - 正确：～させてください（使役形）

2. **否定形不能错误变形**：必须严格遵循「使役形ない + でください」的固定结构。
   - 错误：～させてくださいない（×）
   - 正确：～させないでください（√）

3. **与「～ていただく」的核心区别**：
   | 对比维度 | ～て教えてください | ～ていただけますか |
   |----------|------------------|-------------------|
   | 尊敬度 | 基础请求，略带命令感 | 更加礼貌，标准商务用语 |
   | 适用场景 | 平辈/下级/紧急情况 | 上司/长辈/正式场合 |
   | 语气特征 | 直接请求允许 | 委婉请求许可 |

### 请求表达完整层级

| 形式 | 礼貌度 | 适用场景 |
|------|--------|----------|
| ～てください | 标准礼貌 | 通用请求 |
| ～てちょうだい | 非正式亲近 | 女性/孩童，极亲近私人场景 |
| ～てくれ | 口语随意 | 男性，平辈/晚辈 |
| ～せてください | 使役请求 | 请求允许自己做某事 |
| ～せていただけますか | 非常礼貌 | 商务/对上位的使役请求 |
| ～せていただく | 自谦表达 | 正式场合，尊敬度更高 |
