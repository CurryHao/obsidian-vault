# 语法：～くせに

## 接续
- 动词/イ形容词普通形 + くせに
- ナ形容词词干 + な + くせに
- 名词 + の + くせに
- 口语可变形为「くせして」

## 核心用法详解

### 强烈指责不满
后项结果违背前项理应推导出的正常逻辑，说话人带有轻蔑、指责、不满的负面情绪，仅用于口语。

典型例句：
- 本当に知っているくせに知らないふりをしている。——明明知道却装作不知道
- 子供のくせして酒を飲むなんてとんでもない奴だ。——明明是孩子还喝酒，真是不像话

## 注意
- 和「のに」核心区别：
  - 主语限制：くせに前后主语必须一致，のに无限制
  - 主语属性：くせに前项须是有生命的人/动物，のに可接无生命事物
  - 语气差异：くせに责难语气极强，のに仅偏遗憾意外
  - 客观对比：のに可用于客观对比，くせに无此用法
- 场景误用：正式商务、公文场景中禁用
- 接续错误：ナ形容词/名词需加「な/の」
