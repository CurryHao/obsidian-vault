# 语法：にする

## 接续
- 名词 + にする：选择/决定某个对象，或把事物设定为某种身份
- イ形容词：词尾い→く + する：让事物变为某种状态（暑くする、美味しくする）
- ナ形容词词干 + にする：让事物变为某种状态（きれいにする、便利にする）
- A を B にする：对A进行本质性改造，让A彻底变成B

礼貌体：
- 现在/未来：～にします / ～くします / ～にします
- 过去：～にしました / ～くしました

## 核心用法详解

### 主观选择/决定

从多个选项中主动选定一个，是日常点餐、做选择时最常用的表达。说话人对结果承担主动决策责任。

典型例句：
- 昼ご飯はラーメン**にします** — 午饭我选吃拉面
- 誕生日プレゼントは本**にしました** — 生日礼物我选了书
- A案ではなく、B案**にします** — 不采用A方案，我选B方案

避坑提示：与「にする」对应的客观变化表达是「になる」，**主体意志是否参与**是判断核心。

### 人为改变事物状态

通过人的主动动作，把事物调整到自己期望的状态。多见于调整环境、委婉提要求、表达期许。

典型例句：
- 部屋を涼しく**してください** — 请把房间弄凉快一点
- 試験中ですから、静かに**してください** — 正在考试，请保持安静
- もっと野菜を美味しく**したい** — 想把蔬菜做得更好吃

避坑提示：イ形容词只能用「くする」，ナ形容词和名词只能用「にする」。**「涼しいにする」「静かする」都是错误表达**——这是初级阶段最高频的接续错误之一。

### 把A改造/培养成B（AをBにする）

对A进行本质性、永久性的改造，让它彻底变成B的属性。强调动作过程的投入和最终状态的改变。

典型例句：
- 使わない部屋を倉庫**にしました** — 把不用的房间改造成了仓库
- 息子を医者**にしたい** — 我想把儿子培养成医生
- 彼の提案を採用案**にした** — 把他的提案变成了采用方案

避坑提示：与「AをBとする」对照——「AをBにする」是**永久性、本质性**的实际改造；「AをBとする」是**临时性、表面性**的当作使用（详见相似语法）。

## 注意

### 「にする」vs「になる」

| 维度 | にする | になる |
|------|--------|--------|
| 主语意志 | 人的主观动作（人为改变） | 客观自然变化（自发演变） |
| 主体 | 多为人（说话人主动） | 多为事物（不受人控制） |
| 助词 | ～を / 动作主体用「は・が」 | ～が |
| 中文 | 使之变成…… | 变成……了 |

对照例句：
- 部屋を明るく**しました**（我主动把房间弄亮了 / 主观动作）
- 部屋が明るく**なりました**（房间自然变亮了 / 客观变化）
- 花を赤く**した**（我把花染红了 / 人为操作）
- 花が赤く**なった**（花变红了 / 自然变色）

### 「AをBにする」vs「AをBとする」

| 维度 | AをBにする | AをBとする |
|------|------------|------------|
| 性质 | 本质性、永久性的实际改造 | 临时性、表面性的认定 / 假设 |
| 语体 | 口语、动作描写 | 书面、立场/定义 |
| 焦点 | 动作过程 + 最终状态 | 立场/资格的设定 |

对照例句：
- 部屋を倉庫**にしました**（把房间彻底改造成了仓库 / 实际施工改造）
- 部屋を一時的に倉庫**として使う**（临时把房间当仓库用 / 名义上的使用）

### 「名词+にする」的两种语义不能混用

「名词+にする」在不同语境下分别表示"选择/决定"或"设定为某种身份"，**核心都是人的主观动作**。和「名词+になる」（客观身份/状态变化）严格对立。

- 生徒会会長**にする**（选举/任命为学生会主席 / 主观决定）
- 生徒会会長**になる**（自然成为学生会主席 / 客观结果）

### 不能用于自然变化

花开、天气自然变冷、四季更替等事物自发的变化，绝对不能用「にする」，必须用「になる」。这是初级阶段必考点。

- ✗ 春に**なって**、花が咲いた → 「花が咲く」自然发生
- ✗ 春に**なって**、気温が暑く**なった** → 气温是自然上升
- ✗ 雨に**なって**、道が滑りやすく**なった** → 路滑也是自然结果

## 相似语法
- [[～を～とする]]（临时性 / 表面性的认定与假设）
- [[～になる]]（客观自然变化）
- [[～ことにする]]（个人主观决定做某事）
- [[～ようにする]]（主动坚持与意志努力）
