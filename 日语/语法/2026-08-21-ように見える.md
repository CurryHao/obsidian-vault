# 文法：～ように見える

## 接続
- 名詞 + の + ように見える
- 動詞普通形 + ように見える
- い形容詞普通形 + ように見える
- な形容詞詞幹 + な + ように見える
- 例：先生 + の + ように見える、眠っている + ように見える

## 核心的な用法

### 外見に基づく比喩的印象
形状・見た目から比喩的な印象を表現する。

典型例文：
- あの雲は羊のように見える — 那朵云看起来像绵羊
- 雪のように白い肌 — 雪白的肌肤

### 状態・性質の視覚的推測
外見から状態や性質を推測するが、実際にそうであるとは限らない。

典型例文：
- 彼はとても元気のように見えるが、実は疲れている — 他看起来很精神，但实际上很累
- 彼は何かを隠しているように見える — 他让人觉得好像隐瞒了什么

### 非視覚的総合感覚（外観的な兆候に基づく判断）
純粋な視覚を超え、話し方・仕草など観察可能な現象全体に基づく判断。

典型例文：
- 彼の話し方は、何かを隠しているように見える — 他说话的方式，让人觉得好像隐瞒了什么

## 注意

### 「～ように見える」vs「～に見える」
- **ように見える**：前接完整小句（名詞+の、動詞句、形容詞句）。構造が複雑で、比喩・推測の内容が具体的。
  - 例：彼は眠っているように見える。（他看起来像在睡觉。）
- **に見える**：前接名詞・な形容詞詞幹のみ。簡潔で直接的。
  - 例：彼は先生に見える。（他看上去像个老师。）
  - 例：この生地は丈夫に見える。（这块布料看上去很结实。）

### 「～ように見える」vs「～そうだ（様態）」
- **ように見える**：総合的・主観的な印象。「我觉得/看起来像……」
  - 例：彼は幸せのように見える。（他看起来幸福。→ 整体状態から_personal感受_）
- **そうだ（様態）**：外在の徴候に基づく直観的判断。すぐに起こりそうな事態や物理的性質を描述。
  - 例：彼は幸せそうだ。（他一副幸福的样子。→ 表情・仕草から直接観察）
  - 例：この橋は壊れそうだ。（这桥快要坏了。→ ひび・揺れなどの兆候）

### 自身の一感情表現には使えない
「私は寒いように見える」は不適切。自身の一感情は「私は寒い」或「寒そうに見える」（他角度看）を使う。
