# 语法：～から見ると／から見れば／から見て

## 接续
- 仅能接名词，不能接动词、形容词
- 正确示例：外観から見ると、状況から見れば、第三者の立場から見て
- 错误示例：走るから見ると、暑いから見れば

## 核心用法详解

### 客观观察视角
站在特定观察视角对事物进行客观观察得出结论，三形态大多可互换。

- ～から見ると：最通用基础形态
  この足跡から見ると、犯人は男性だと推測できる。——从脚印看可推测犯人是男性

- ～から見れば：假定形态，推测感更强
  親から見れば、子供はいくつになっても子供のままだ。——在父母看来孩子永远是孩子

- ～から見て：强调观察依据来源
  今回の点数から見て、彼はまだ合格ラインに達していない。——从分数看他没达到及格线

## 注意
- 和「～から言うと」区别：前者客观观察，后者主观立场
- 和「～からすると」区别：前者是观察视角，后者是客观事实依据
- 接续错误：直接接动词/形容词违反规则
- 语义误用：不用于物理空间起点
