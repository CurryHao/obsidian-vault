# 语法：もらう／いただく

## 接续
- 动词て形 + もらう／いただく
- Aは Bに/から Cを もらう／いただく（A是接受者，B是给予者，C是得到的对象）

## 核心用法详解

### 用法一：普通接受（もらう）
表示说话人或己方的人，主动从对方那里得到物品、恩惠。核心逻辑是"我主动索要/收下"，接受者是句子的主语。

典型例句：
- 私は友達から誕生日プレゼントをもらいました。 — 我从朋友那里收到了生日礼物。
- 田中さんにパソコンを直してもらいました。 — 我请田中帮我修好了电脑。
- 友達に日本語を教わりました。 — 我请朋友教我日语。

避坑提示：对长辈、上司使用「もらう」会显得非常失礼，必须替换为「いただく」。

### 用法二：自谦接受（いただく）
「もらう」对应的自谦敬语形式，用于从长辈、上司等地位高于自己的对象那里得到物品、恩惠，通过压低自己表达尊重，语气非常谦恭。

典型例句：
- 私は先生から貴重な資料をいただきました。 — 我从老师那里得到了珍贵的资料。
- 部長にスケジュールを調整していただきました。 — 承蒙部长帮我调整了日程。
- 先生にご指南いただきました。 — 承蒙老师指导。

避坑提示：
- 「いただく」不能用于地位低于自己的对象，否则显得过度客套。
- 商务请求时，「～ていただけませんか」比普通请求委婉很多，几乎是标准用法。

### 用法三：补助动词「～てもらう」
接受者主动请求、收下同辈/平级对象为自己做的动作恩惠，视角完全站在接受者自身。

标准句型：接受者 は 授予者 に(から) 动作对象 を 动词て形 + てもらう

典型例句：
- 友達に駅まで送ってもらいました。 — 朋友把我送到了车站。
- 辞書を忘れたので、隣の席の人に貸してもらいました。 — 忘带词典了，我找邻座的人借了一本。

语气特征：客观陈述"我得到了对方的帮助"，没有过度夸张的感恩语气，是日常对话的通用表达。

### 用法四：补助动词「～ていただく」
「～てもらう」的自谦敬语形态，专门用于承蒙长辈、上司等上位者为自己提供动作恩惠，通过压低自身姿态表达对对方的尊重。

标准句型：接受者 は 授予者 に(から) 动作对象 を 动词て形 + ていただく

典型例句：
- 先生に日本語の作文を直していただきました。 — 承蒙老师帮我修改了日语作文。
- 部長にプロジェクトのアドバイスをしていただきました。 — 承蒙部长给了我项目的相关建议。

衍生高频考点：「～ていただけませんか」是它的可能态否定疑问形式，译为"能否请您帮我……"，是高考日语、JLPT考试中最高频的礼貌请求句型。

### 用法五：独立语义"吃、喝"
「いただく」还有一个独立常用语义"吃、喝"，是「食べる／飲む」的自谦语，注意不要和授受用法混淆。

典型例句：
- ごちそうさま、いただきました。 — 多谢款待，我吃过了。
- 昼ご飯を食べました。 → 昼ご飯をいただきました。（更礼貌）

## 注意

### 授受动词体系完整对应
- 给予侧：あげる ↔ さしあげる（我自他）
- 接受侧：もらう ↔ いただく（他自我）
- 他人给我：くださる（敬语，不用自谦）

### 核心考点
- 主语永远是"我/我方"，不能把授予者作为句子主语，这是选择题里最常见的出题陷阱。
- 该系列句型与「～てくれる」的核心区别：「～てくれる」侧重对方主动为我做事，「～てもらう」侧重我主动请求/收下对方的帮助。

| 对比维度 | ～てもらう | ～ていただく |
|----------|-----------|-------------|
| 适用对象 | 同辈、朋友、平级 | 长辈、上司、客人 |
| 语气属性 | 日常中立，无敬语属性 | 自谦敬语，带有强烈的谦恭感恩感 |
| 核心逻辑 | 客观陈述"我得到了帮助" | 强调"承蒙对方施恩"的谦逊态度 |
| 考试定位 | N3基础授受必考题 | N2敬语高频核心考点 |

### 其他注意事项
- 给动植物喂食、浇水等场景，二者都不能使用，必须用「やる」的反向——不用于动植物。
- 商务邮件中「～していただけますでしょうか」是极常用的委婉请求表达。
