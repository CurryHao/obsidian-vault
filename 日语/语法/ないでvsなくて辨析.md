# 语法：ないで vs なくて 辨析表

## 核心区别速查表

| 对比项 | 「ないで」 | 「なくて」 |
|--------|-----------|-----------|
| **接续限制** | 仅接动词/动词型助动词 | 可接动词、い形容词、な形容词、名词 |
| **语义侧重** | 主观意志、动作附带状况 | 客观原因、状态描写 |
| **典型场景** | 命令/请求、逆态转折 | 原因/理由、状态并列 |
| **书面替代** | ～ずに | ～ず（文语残留，较少用） |

## 分项详解

### 1. 接续规则对比

**只能用「ないで」的场景**：
- 接动词未然形后
  - 例：行かないで → ✓ / 行かなくて → △（语义不同）

**只能用「なくて」的场景**：
- 接形容词/形容动词后表状态否定
  - 例：高くない → 高くなくて ✓ / 高くないで ✗
  - 例：暇だ → 暇じゃなくて ✓ / 暇じゃなければ ✗

**可互换场景**：
- 接动词后表并列对比
  - 例：行かないで見る / 行かなくて見る（语义相近）
- 接在「いい」前构成许可句型
  - 例：行かないでいい / 行かなくていい（语义相近）

### 2. 语义差异对比

**只能用「ないで」的场景**：
- 表主观命令/请求
  - 例：しないで！（别做！）→ 不能用「しなくて」
- 表动作附带状况
  - 例：食べないで出勤した（没吃饭就去上班了）→ 强调主观选择
- 表逆态转折（"明明没做…却…"）
  - 例：勉強しないで合格した（没学习却及格了）→ 强调意外

**只能用「なくて」的场景**：
- 描写客观的负面状态
  - 例：お金がなくて困る（没钱很为难）→ 客观原因
- 表原因/理由（后项为自然结果）
  - 例：病気じゃなくて無理だ（不是生病，是没力气）→ 客观说明

### 3. 考试高频考点

**考研二外日语考点分布**：
- 70%集中在"接续规则"辨析
- 20%考察"语义差异"理解
- 10%为听力场景应用

**易错题类型**：
1. 形容词否定后接续判断
   - 例：この問題は難しくて解けない（✓）/ 難いんじゃない（✗）
2. 原因与附带状况的辨析
   - 例：雨で遅れた（客观原因）/ 雨が降らないで出了かけた（主观选择）
3. 命令/请求场景的固定搭配
   - 例：待たないで！（主观命令）/ 待たなくていい（许可）

## 记忆技巧
- **ないで** = 主观动作的"不带"（没带A就做了B）
- **なくて** = 客观状态的"不+且"（不A而且B）
