# 语法：～上に

## 接续
- 动词普通形/イ形容词辞书形 + 上に
- ナ形容词词干 + な + 上に
- 名词 + である/の + 上に

## 核心用法详解

### 表递进累加
在前项基础上追加属性，相当于「～だけでなく」。

典型例句：
- そのスポーツクラブは入会金がいらない上に、我が家から近い。——不仅免入会费，而且离家近

### 可独立作接续词
变形为「その上」，直接连接两个独立句子，语义和「さらに」一致。

## 注意
- 后项不能接命令、禁止、委托、劝诱类表达，如「安い上に、おいしいものを食べにしましょう」是错误用法
- ナ形容词/名词后续需加「な/である」，不可直接接「上に」
- 多用于书面语，比口语「それに」更正式
