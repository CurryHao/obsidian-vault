# 语法：たりします

## 接续

所有词类先变成**た形**，后续接「り」；两个及以上「たり」并列之后，句尾统一接「する / します / した」收尾。

| 词类 | 变形规则 | 例 |
|------|---------|----|
| 一类（五段）动词 | た形 + り | 買う → 買**ったり**、走る → 走**ったり** |
| 二类（一段）动词 | た形 + り | 食べる → 食べ**たり**、見る → 見**たり** |
| 三类动词 | た形 + り | する → し**たり**、来る → 来**たり** |
| イ形容词 | 去词尾い + かったり | 甘い → 甘**かったり** |
| ナ形容词 / 名词 | 词干 + だったり | 静かだ → 静か**だったり**、休みだ → 休み**だったり** |

注意：句尾的时态变化只能落在最后的「する / します / した」上，前面所有「たり」**不能再做时态变形**。

## 核心用法详解

### 部分列举代表性动作（过去・日常）

最经典的基础用法，列举过去或日常发生的多个代表性动作，**不代表穷尽**全部行为，只是举出代表性例子。

典型例句：
- 週末は映画を見**たり**、買い物をし**たり**しました — 周末看了电影、逛了街之类的
- 休みの日は本を読**たり**、散歩し**たり**します — 休息日读读书、散散步之类的
- 子供たちは公園で遊ん**たり**、お弁当を食べ**たり**していました — 孩子们在公园玩耍、吃便当之类的

避坑提示：句尾「しました / します / する」控制整句时态，前项「たり」只表示"并列的项目"，不独立表时态。

### 单「たり」委婉举例

只放一个「たり」用来委婉地举出一个代表性例子，传递"……之类的"的不确定语气。**日常口语里非常常用**。

典型例句：
- 消しゴムを持っ**たり**していますか — 你带橡皮擦之类的东西了吗？
- 何か飲み物を買っ**たり**しましょう — 买点饮料之类的吧
- 後で連絡した**り**しますね — 回头联系你之类的

避坑提示：单「たり」语气比"具体列举"更含蓄，常用于不想直接下结论或显得太肯定的场合。

### 反覆对立状态

用两个完全相反的动作/状态并列，表达"时而……时而……"的反复变化。

典型例句：
- 天気が変わりやすくて、晴れ**たり**雨が降っ**たり**します — 天气多变，一会儿晴一会儿下雨
- 株価は上がっ**たり**下がっ**たり**しています — 股价一会儿涨一会儿跌
- 子供の頃は泣い**たり**笑っ**たり**していました — 小时候一会儿哭一会儿笑

避坑提示：反覆对立用法下，前后项必须语义对立或交替，否则只是普通列举。

### 未来计划列举

用来列举未来打算做的多个备选事项，**不代表全部行程都确定**。

典型例句：
- 旅行中は観光し**たり**、美味しいものを食べた**り**する予定です — 旅行时打算观光、吃美食之类的
- 夏休みは泳い**たり**、山に登っ**たり**したいです — 暑假想去游泳、爬山之类的

避坑提示：未来计划用法经常搭配「予定」「つもり」「たい」等表达未来意愿的词。

## 注意

### 与其他并列助词的核心区分

| 对比点 | たり | と | や | し |
|--------|------|-----|-----|-----|
| 语义 | 部分列举动作/状态 | 完全并列全部事物 | 部分列举事物 | 并列多个理由/事实 |
| 是否列全 | 不列举全部 | 列举全部 | 不列举全部 | 不列举全部 |
| 典型搭配 | ～たり～たりする | AとB | AやB | Aし、Bし |
| 词类范围 | 动词/形容词/名词 | 主要名词 | 主要名词 | 句子 |

具体例：
- 週末は映画を見**たり**買い物**をしたり**しました（列举了部分周末活动）
- 週末は映画**と**買い物**を**しました（周末只做了看电影和购物这两件事）
- 机の上に本**や**ペン**が**あります（桌上有书和笔等东西）
- 安い**し**、便利**だし**、この店が好きです（因为便宜又方便，所以喜欢这家店）

### 常见衍生搭配

**～たりもする**：强调某个动作偶尔会发生，补充额外的小概率情况。

- 時々ゲームをし**たりもする** — 我偶尔也会玩玩游戏
- 甘いものを食べ**たりもする** — 偶尔也吃甜食

**～たりしないで**：口语里用来委婉批评、制止对方的不当行为。

- 人をからかっ**たりしないでください** — 请不要捉弄别人
- 嘘をつい**たりしないでね** — 不要说谎哦

### 高频易错点

- **时态集中点**：「たり」本身只表示并列，句尾时态只能放在最后的「する」上。✗「見たり見たりしました」（双「たり」接过去时错误）→ 「見たり見たりします」（并列表达反复）
- **数量限制**：并列的「たり」数量日常使用以 **2 个**最为常见，最多一般不超过 3 个。列举太多会显得非常啰嗦，母语者更倾向用「～とか～とか」或分多个句子表达
- **不同词类的混合列举**：可以混合动词、形容词、名词，但语义要属于同一范畴。✗「映画を見たり、暑かったりします」语义上不通——电影和温度不属于同一类
- **礼貌体的位置**：时态・礼貌体只落在最后的「する」上。✗「見ましたり、食べたりします」（多余变形）→ 「見たり、食べたりしました」

### 「たりする」vs「とき」

「たりする」表"反复发生或代表性的若干动作"，「とき」表"在做某事的时候"。两者结构不同：
- テレビを見**たりする**（有时候看电视之类的 / 反复或习惯）
- テレビを見る**とき**（看电视的时候 / 时间点）
