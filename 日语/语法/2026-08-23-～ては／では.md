# 语法：～ては／では

## 一、基础接续规则
动词‌：动词て形 + は → 即「～ては」
イ形容词‌：イ形容词词干 + くて + は → 即「～くては」
ナ形容词/名词‌：ナ形容词词干/名词 + で + は → 即「～では」

## 二、核心常见用法
假定条件（负面倾向）‌
表示如果出现前项的情况，就会引发不好的、不受欢迎的后项结果
例句：雨が降っては、試合が中止になる：要是下雨的话，比赛就要中止了
动作反复循环‌
表示同一个动作不断重复、交替发生，带有“一做就……”的语感
例句：食べては寝、食べては寝て、太ってしまった：吃了睡、睡了吃，结果长胖了
限定范围‌
接在名词后，限定动作发生的场景、身份、范围
例句：学生ではそんな高い買い物はできない：作为学生，买不起那么贵的东西
固定否定搭配‌
衍生出「～てはいけない」「～てはならない」等固定句型，语义为“禁止、不可以”
例句：ここでタバコを吸ってはいけない：这里不可以抽烟

## 三、高频易错点
注意和单纯的て形中顿区分：加了「は」之后，句子会额外带上“条件限定、强调反复”的语气，不是单纯的动作先后衔接
「～では」在口语中经常发生音变，缩略成「じゃ」，比如「それでは」日常口语常说成「それじゃ」
