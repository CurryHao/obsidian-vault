# 语法：なければなりません

## 接续

本质是「～ない假定形 + なりません」的复合结构。变形分三类：

| 词类 | 变形规则 | 例 |
|------|---------|----|
| 动词 | ない形去掉「い」+ なければなりません | 行く → 行か**なければなりません**、食べる → 食べ**なければなりません** |
| イ形容词 | 词尾「い」→「く」+ なければなりません | 早い → 早**くなければなりません**、高い → 高**くなければなりません** |
| ナ形容词 | 词干 + でなければなりません | 静か → 静か**でなければなりません** |
| 名词 | + でなければなりません | 学生 → 学生**でなければなりません** |

注意礼貌体「なりません」对应普通形「ならない」，过去时用「なりませんでした」。

## 核心用法详解

### 客观强制义务（核心义）

本质是双重逻辑叠加：
- 「～なければ」= 如果不做某事的话
- 「なりません」= 行不通、不成立

两者叠加后形成"如果不做这件事就无法成立，所以必须去做"的强制义务语义。**只用来描述客观层面的强制**——法律、规则、责任、社会常识。

典型例句：
- 明日試験があるので、今日勉強**しなければなりません** — 明天有考试，所以今天必须学习
- 契約書にサインしなければなり**ません** — 必须在合同上签字
- 病院では静かで**なければなりません** — 医院里必须保持安静
- 期限までに提出しなければなり**ません** — 必须在期限之前提交

避坑提示：**「なければなりません」只能描述客观强制义务**，不能用来表达个人主观强烈意愿。如果想表达"我一定要去日本"这种个人主观意愿，应用「日本に行きたいです」。

### 不同礼貌等级变体

根据场景的正式程度，有四个变体在日语实际使用中并存：

**1. 礼貌体：なければなりません**

正式商务、职场、书面场景。强制感最强。

- 会議に必ず出席しなければなり**ません** — 必须出席会议
- ご契約の内容をご確認の上、サインしなければなり**ません** — 请确认合同内容后签字

**2. 简体礼貌体：なくてはいけません / なくてはいけない**

日常对话、熟人之间的提醒。义务感稍弱，更偏向"情理上应该做"。

- 早く帰ら**なくてはいけません** — 得早点回去
- 宿題をやら**なくてはいけない** — 得写作业

**3. 简体口语：なきゃ / なくちゃ**

年轻人最常用的缩略形式，语气非常随意。男性「なきゃ」女性「なくちゃ」使用偏多。

- 早く行かな**きゃ** — 得赶紧走了
- もう帰ら**なくちゃ** — 得回家了

**4. 书面正式：ねばならない**

多用于法律条文、公司规章制度、正式文书里，强制感最强。

- 期限までに提出せ**ねばならない** — 必须于期限前提交
- 関係者以外立ち入るべからず（禁止入内 / 法律文书固定表达）

变体强度排序：
**ねばならない（书面最强）> なければなりません（商务正式）> なくてはいけません（日常礼貌）> なきゃ/なくちゃ（口语最随意）**

## 注意

### 与「べきだ」的核心区别

| 维度 | なければなりません | べきだ |
|------|-------------------|--------|
| 义务来源 | 规则、法律、客观责任 | 道义判断、社会责任 |
| 强制程度 | 强制执行 | 应该做，但未必强制 |
| 语气 | 客观、报告事实 | 主观判断、价值判断 |

例：
- 医者だから患者を救わ**なければなりません**（因为是医生所以必须救 / 客观责任）
- 医者なら患者を救う**べきです**（作为医生应该救 / 道义判断）

### 与「なくてもいい」的核心区别

「なければなりません」= 必须做（强制）
「なくてもいい」= 不做也没关系（允许）

两者是完全反义表达，常以配对形式出现在 JLPT 考题中：

- 薬を飲ま**なければなりません**（必须吃药 / 强制）
- 薬を飲ま**なくてもいい**（不吃药也可以 / 允许）

### 与「てもいい」（允许）的核心区别

「てもいい」= 做也可以（许可），与「なければなりません」的强制方向相反。

- ここで休ん**でも構いません**（在这里休息也可以 / 许可）
- ここで休ま**なければなりません**（必须在这里休息 / 强制）

### 高频易错点

**1. ナ形容词/名词的「で」不能漏**

这是考试里最常见的出题陷阱：
- ✗ 静か**くなければなりません**（错误 / 漏了「で」）
- ○ 静か**でなければなりません**
- ✗ 学生**くなければなりません**（错误 / 漏了「で」）
- ○ 学生**でなければなりません**

「静か」是ナ形容词词干，必须后续「で」中顿再接假定形，**不能直接加「く」**。

**2. 不能用来表达个人主观意愿**

「なければなりません」只能描述客观强制，主观强烈意愿应该用「たいです」或「つもりです」：
- ✗ 日本に行かなければなり**ません**（"我一定要去日本"——主观意愿错例）
- ○ 日本に行きた**いです**（我想去日本 / 个人主观意愿）

**3. 与其他假定形的混淆**

「なければなりません」= 「～ない假定形 + なりません」。「假定形」家族的完整辨析：
- 「～ば」= 假定条件（如果……的话）
- 「～なければ」= 否定假定（如果不……）
- 「～なければならない」= 否定假定 + 否定结果（如果不……就不行）
- 「～なければなりません」= 「～なければならない」的礼貌体

三个表达层层递进，最终叠加出"必须"的强制语义。

**4. 时态转换**

- 现在时：なければなりません
- 过去时：なければなりません**でした**（过去必须做但没做 / 遗憾语气）

## 相似语法
- [[ねばならない|～ねばならない]]（书面正式版，强制感最强）
- [[べきだ]]（道义判断"应该"，主观色彩更浓）
- [[てもいい|～てもいい]]（许可，与强制方向相反）
- [[なくていい|～なくていい]]（允许不做，反义表达）
