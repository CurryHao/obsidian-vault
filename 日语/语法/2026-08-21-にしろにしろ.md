# 文法：～にしろ～にしろ

## 接続
- 名詞 + にしろ + 名詞 + にしろ
- 動詞普通形 + にしろ + 動詞普通形 + にしろ
- い形容詞普通形 + にしろ + い形容詞普通形 + にしろ
- な形容詞詞幹 / である + にしろ + な形容詞詞幹 / である + にしろ
- 口語：「～にせよ～にせよ」「～にしても～にしても」

## 核心的な用法

### 対立する二極を列挙し、結論の普遍性を強調する
正反対または対立的な選択肢を挙げて、「どちらであっても結果は同じ」という条件を提示する。

典型例文：
- 賛成にしろ反対にしろ、はっきりした意見を出してほしい — 无论是赞成还是反对，都希望你提出明确的意见
- 成功するにしろ失敗するにしろ、貴重な経験になる — 成功也好，失败也罢，都会成为宝贵的经验

### 同種の代表例を挙げて総括する
特定のカテゴリーから代表例を二つ挙げ、カテゴリー全体に通用することを示す。

典型例文：
- 牛肉にしろ豚肉にしろ、十分に加熱して食べてください — 不管是牛肉还是猪肉，都请充分加热后食用
- 雨にしろ雪にしろ、明日は外出できません — 不管是下雨还是下雪，明天都不能出门

### 事態の可能性を網羅的に列挙する
起こりうる複数のケースをすべてカバーし、「いずれにしても」という結論を導く。

典型例文：
- 行くにしろ行かないにしろ、連絡は必要だ — 去也好，不去也罢，都需要联系一下
- 高いにしろ安いにしろ、自分にとって必要なものを買えばいい — 贵也好便宜也罢，买自己需要的东西就好

## 注意

### 「～にしろ～にしろ」vs「～でも～でも」
- **にしろにしろ**：書面的・論理的。無条件の総括を強調。「无论哪种情况都……」。
  - 例：雨天にしろ晴天にしろ、試合は決行する。（正式公告的语气。）
- **でもでも**：口語的・随意的。無差別な列挙を強調。「不管……都……」。
  - 例：雨でも晴れでも、試合はやる。（日常随意的语气。）

### 「～にしろ～にしろ」vs「～であれ～であれ」
意味・用法はほぼ同一。「であれであれ」は文語的残留で、より硬く古風な語感。極めて公式な文書や演説で使用される。

### 「～かどうか」との関係
「～にしろ～にしろ」は「～かどうか」の二つの可能性を具体的に開陳した表現。前者の方が語感が強く、より断定的。

- 合格するかどうかは別として、全力を尽くした。（是否能及格先不论，我已尽全力。）
- 合格するにしろしないにしろ、全力を尽くした。（及格也好，不及格也罢，我已尽全力。）→ より強く、より完全に網羅。

### 疑問文には使えない
陈述语气で、疑問文は不可。「行くにしろ行かないにしろですか？」は誤り。
