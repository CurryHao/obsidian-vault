# 四大假定语法对比汇总

## 接续规则对比

| 语法 | 动词 | い形容词 | な形容词/名词 |
|------|------|----------|---------------|
| **たら** | 辞书形/ない形等简体 + たら | 词尾い→く + らら | 词干 + だったら |
| **と** | 辞书形等简体 + と | 词尾い + と | 词干 + だと |
| **なら** | 辞书形等简体 + なら | 词尾い + なら | 词干 + なら |
| **ば** | う段→え段 + ば；る段→去る+れば | 词尾い→けれ + ば | 词干 + であれば |

> 「なら」接续最宽松，几乎所有简体形直接加なら。「ば」变形规则最复杂，考试高频考点。

## 核心语义对比

| 语法 | 核心语义 | 典型场景 | 后句限制 |
|------|----------|----------|----------|
| **たら** | 前项完成后，后项随即发生 | 口语对话、日常条件 | 无限制 |
| **と** | 一旦前项成立，后项必然发生 | 客观规律、自然现象 | **绝对不能接意志・命令・推测** |
| **なら** | 以对方话题为前提给出建议 | 话题承接、反事实假设 | 多为建议、判断 |
| **ば** | 基于逻辑推导的条件判断 | 理性分析、越…越… | 多为判断、评价 |

## 动作顺序对比（重点考点）

| 语法 | 动作顺序 | 记忆口诀 |
|------|----------|----------|
| **たら** | 先A后B（A完成后做B） | 「たら」事後 |
| **なら** | 先B后A（A开始前完成B） | 「なら」事前 |
| **と** | A与B几乎同时发生 | 一…就… |
| **ば** | 逻辑前提→结果 | 条件→推断 |

例句对比：
- 日本へ行く**なら**、事前に日本語を勉強しておく — 去之前先学日语（事前）
- 日本へ**行ったら**、日本語を勉強しなさい — 到了日本之后再学（事後）

## 高频易错点汇总

| 错误类型 | 错误示例 | 正确示例 |
|----------|----------|----------|
| 「と」后接意志表达 | × 食べると、行きましょう | ○ 食べたら、行きましょう |
| 「ば」变形错误 | × 行くば / 食べるば | ○ 行けば / 食べれば |
| 「なら」接续错误 | × 静かだなら | ○ 静かなら |
| 「たら」与「なら」混淆 | × 日本へ行ったら、事前に勉強する | ○ 日本へ行くなら、事前に勉強する |

## 考试策略

### 高考/JLPT常见考点

1. **「もし」的后续搭配**：考查「もし」后是否接假定类表达
   - 正确：もし + たら/なら/ば/かもしれない
   - 错误：もし + から/と（语义冲突，不可搭配）

2. **「と」vs「たら」**：考查后句是否可接意志表达
   - 后句为命令、意志、劝诱 → 选「たら」
   - 后句为客观结果、自然现象 → 两者皆可，但「と」更强调必然性

2. **「なら」vs「たら」**：考查动作先后顺序
   - 事前准备 → 选「なら」
   - 事后行动 → 选「たら」

3. **「ば」变形**：考查动词变位规则
   - う段动词→え段（行く→行けば）
   - る段动词→去る+れば（食べる→食べれば）

4. **「ば～ほど」固定句型**：越…越…
   - 必ず確認：动词假定形 + ば + 同じ动词辞书形 + ほど

### 解题技巧
- 看到后句是意志/命令/推测 → 排除「と」
- 看到事前准备场景 → 选「なら」
- 看到事后行动场景 → 选「たら」
- 看到变形选项 → 检查动词变位是否正确
- 看到「～ほど」 → 找「ば」的固定搭配
