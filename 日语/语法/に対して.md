# 文法：～に対して

## 接続
- 名詞 + に対して
- 数詞 + 一対 + に対して

## 核心的な用法

### 功能一：動作・感情・態度の対象（对/向……）
動作・感情・態度が特定の相手へ向けられることを示す。

典型例文：
- 先生は学生に対して厳しく指導した — 老师对学生进行了严格的指导
- 彼の失礼な態度に対して、怒りを感じた — 对于他失礼的态度，我感到愤怒
- 子供に対して優しく接する — 对孩子温柔对待

### 功能二：対比・照応（与……相比）
二つの事物を並べて比較する。値・程度・性質の差異を強調。

典型例文：
- 男性に対して、女性の方が寿命が長い — 与男性相比，女性寿命更长
- 輸入車に対して、国産車は価格が安い — 相对于进口车，国产车价格更便宜
- 東京に対して、地方は物価が低い — 与东京相比，地方物价更低

### 功能三：比例・対応（每……）
数量・単位と対応する量を結びつける。比率・配比を示す。

典型例文：
- 生徒一人に対して指導員が一人つく — 每名学生配备一名指导员
- この薬は一日に対して三回服用してください — 这种药每天请服用三次
- 社員100人に対して管理者は5人いる — 员工100人中管理者有5人

### 功能四：定语修饰名词（～に対する + 名词）
「～に対する」为连体形，直接修饰后面的名词。

典型例文：
- 彼の上司に対する態度は問題だ — 他对上司的态度有问题
- 環境問題に対する関心が高まっている — 对环境问题的关注度正在提高
- 私たちへの期待に応えたい — 想回应大家对我们的期待

## 注意

### 「～に対して」と「に」の違い
- **に**：単純な間接目的語。「～に贈る」「～に教える」などの基本的な対象。
  - 例：彼女に花を贈る。（送花给她。）
- **に対して**：意識的に特定の対象に態度や行為を向ける。「對待」の意味合いが強い。より公式。
  - 例：彼女に対して誠実である。（对待她非常真诚。→ 持续的態度）

### 「～に対して」と「について/に関して」の違い
- **に対して**：人・団体に向けられた行動・態度・反応を表す。「**对**某对象采取行动/态度」。
  - 例：質問に対して答える。（对提问作出回答。）
- **について/に関して**：事・物・主題をめぐって思考・議論・調査を行う。「**关于**某主题进行谈论/思考」。
  - 例：質問について考える。（关于提问进行思考。）

### 「～に対して」と「にとって」の違い
- **に対して**：外部から他者へ向けられる行為・態度。施す側の視点。
  - 例：彼に対して厳しい。（**对他**很严厉。→ 我施加于他的态度。）
- **にとって**：内部からの価値判断・評価。対象の立場からの視点。
  - 例：彼にとって厳しい。（**对他而言**很严厉。→ 从他（或某个立场）来看觉得严苛。）

### 「～に対しては/にも」の強調形
- **に対しては**：対象を特に強調。「**至于**……方面」的语气，常带有对比或转折的语感。
  - 例：費用については問題ないが、時間**に対しては**余裕がない。（费用没问题，但时间方面没有余地。）
- **に対しても**：追加的対象。「**也对**……」
  - 例：先生には感謝している。友達**に対しても**親切だ。（不仅对老师心怀感激，对朋友也很友善。）
