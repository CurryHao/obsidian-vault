# 文法：たつもりだ

## 接続
- 動詞（た形）+ つもりだ
- 名詞 + の + つもりだ
- ナ形容詞（词干）+ な + つもりだ
- イ形容詞（辞書形）+ つもりだ
- 動詞（ている形）+ つもりだ
- 動詞（ない形）+ つもりだ

## コア概念

「～つもりだ」的中高级引申用法，核心含义是「自以为这样，但事实并非如此」。说话人主观上坚信自己处于某种状态、完成了某件事，但实际情况完全不是这样，多带有自嘲、无奈的语感。

---

## 用法一：自我认知与客观事实不符

核心语义：说话人主观上坚信自己处于某种状态、完成了某件事，但实际情况完全不是这样，多带有自嘲、无奈的语感。

典型例句：
- 自分がまだ元気なつもりだったけど、一日ハイキングしただけで疲れ倒れそうだった。——自己还以为身体很硬朗，结果只走了一天的徒步就差点累趴下。
- 私は彼女に親切にしたつもりなんですが、感謝されるどころか恨まれました。——我自以为对她已经够好了，结果别说感谢，反倒被她怨恨了。
- 頑張ったつもりだったが、結果は悪かった。——自以为很努力了，但结果不好。
- 説明したつもりでしたが、全然伝わっていなかった。——自以为解释清楚了，但实际上完全没传达清楚。
- 準備万全だと思っていたつもりだったが、実は重要な物を忘れていた。——自以为准备万全了，其实漏掉了重要的东西。

结构特征：
- 动词た形 + つもりだ + が/んだけど（后半句必然出现与主观认知相反的事实）
- 几乎都会搭配转折句使用，后半句一定会出现和前半句主观认知相反的客观事实描述

---

## 用法二：自我假想代入的虚拟状态

核心语义：现实中并没有发生这件事，但说话人在主观上把自己代入成已经完成该动作的状态，多用于自我安慰、自我鼓励的场景。

典型例句：
- 100万円もらったつもりで、貯金しよう。——就当自己拿到了100万日元，开始存钱吧。
- 先生になったつもりで、説明してみて。——你就把自己当成老师，试着讲解一下。
- 成功したつもりで自分を鼓舞する。——把自己想象成已经成功了来鼓舞自己。
- 彼氏がいるつもりで、勇気を出した。——假装自己有男朋友，鼓起勇气去说了。
- 合格したつもりで、喜んでいる。——假装已经合格了，在高兴。（其实还没出成绩）

注意：此处「たつもり」表示的是一种**心理投射**，现实中并未发生，但通过自我暗示来获得心理上的满足或动力。

## 高频考点辨析

### ① 动词基本形+つもりだ vs 动词た形+つもりだ

| | 动词基本形+つもりだ | 动词た形+つもりだ |
|---|---|---|
| 语义 | 真实存在的未来计划 | 和事实不符的主观假想 |
| 时间维度 | 事先已经敲定的安排 | 当下主观的自我认知 |
| 真实性 | 计划是真实存在的 | 事实与认知相反 |
| 示例 | 日本へ行くつもりです。——打算去日本（真实计划） | 行ったつもりだ。——自以为去了（其实没去） |

关键区别：
- 「行くつもり」= 真的打算去（计划存在）
- 「行ったつもり」= 以为自己去过了（其实没去，主观假想）

---

### ② たつもりだ vs つもりでした（原打算）

| | たつもりだ | つもりでした |
|---|---|---|
| 语义 | 自以为……其实不然 | 原本打算……但最终没实现 |
| 计划真实性 | 计划从一开始就是主观假想，没有实际发生 | 计划曾经真实存在过 |
| 事实状态 | 动作实际上没有做 | 动作实际上没有做成 |
| 示例 | 食べたつもりだ（自以为吃了，其实没吃） | 食べるつもりだった（本打算吃，但没吃成） |

典型真题翻译：
- 彼は事件の原因を知っているつもりだが、本当に何も知らない。——他还以为自己知道事件的原因呢，其实他什么都不知道。

易错点：不能把「たつもりだ」翻译成「原打算做了某事」，它和表过去计划落空的「つもりでした」语义完全不同。

---

### ③ たつもりだ vs と思っている

| | たつもりだ | と思っている |
|---|---|---|
| 语义 | 主观假想与事实不符 | 持续持有的想法或判断 |
| 事实关系 | 通常与事实相反 | 可能是事实，也可能不是 |
| 语感 | 自嘲、无奈 | 中性陈述 |
| 示例 | 説明したつもりだ（自以为解释了，其实没解释清楚） | 説明していると思っている（自以为在解释） |

---

## 注意

### 接续要点
1. **动词た形是最核心接续**，占N3考试该语法题型的80%以上
2. **其他延伸接续**：名词（の形）、ナ形容词（な形）、イ形容词辞书形、动词ている形、动词ない形都可以直接后续「つもりだ」
   - 名詞 + の + つもりだ：学生だと思ったつもりだった（自以为是个学生）
   - ナ形容詞 + な + つもりだ：元気なつもりだった（自以为很有精神）
   - イ形容詞 + つもりだ：美味しいと思ったつもりだ（自以为很好吃）

### 考试易错点
1. **该句型几乎都会搭配转折句使用**，后半句一定会出现和前半句主观认知相反的客观事实描述，这是考试中识别该句型的核心标志
2. **不能翻译成「原打算做了某事」**，它和「つもりでした」语义完全不同
3. **与基础形「动词基本形+つもりだ」的区分**：基础形表真实存在的未来计划，而「たつもりだ」表和事实不符的主观假想
4. **JLPT N3考试中，经常和基础形「つもりだ」作为干扰项组合出题**
