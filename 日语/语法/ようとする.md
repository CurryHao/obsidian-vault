# 语法：～（よう）とする

## 接续
- 五段动词：词尾う段假名→お段假名 + う
  - 書く → 書こうとする
  - 死ぬ → 死のうとする
- 一段动词：去掉词尾「る」+ ようとする
  - 食べる → 食べようとする
  - 見る → 見ようとする
- 特殊动词：
  - くる → こようとする
  - する → しようとする
- 否定形式：～（よう）としない（表"完全不想、根本不打算"）

## 核心用法详解

### 用法一：动作正要开始/即将发生
含义：描述某个动作马上就要启动的临界状态，中文译为"正要、刚要……"。常与「たら/が」连用，引出突发状况。

典型例句：
- お風呂に入ろうとしていた時、電話が入った — 正要洗澡的时候，电话来了
- 家を出ようとしたら、雨が降り出した — 正要出门的时候，突然下起了雨

避坑提示：与「～たところ」区别，「ようとする」强调动作即将开始的瞬间，而非动作已完成。

### 用法二：努力尝试做某一行为
含义：主观上付出努力想要达成某个目标，强调"尝试、拼命想要"的过程。

典型例句：
- 息子は北京大学に入ろうとしています — 我的儿子正打算考入北京大学
- 必死に立ち上がろうとしたが、足が痛くてできなかった — 拼命想要站起来，但是脚太疼了做不到

注意：此用法强调"尝试中"的状态，结果可能成功也可能失败。

## 注意
- 意志形接续是N3考试高频考点，错误变形常作为干扰项
- 否定形式「～（よう）としない」带有强烈指责语气，表"对方根本不肯做某事"，听力题高频
- 描述正要做某事时突发意外的剧情，后半句常接「たら/が」引出突发状况
