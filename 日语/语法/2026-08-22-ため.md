# 语法：～ため（に）

## 接续
- **表目的**：意志性动词基本形 + ために；名词 + の + ために
- **表原因**：动词/形容词简体形 + ために；名词/な形容词 + な + ために

典型例句：
- 留学する**ために**勉強している — 为了留学在努力学习（目的）
- 健康**のために**運動する — 为了健康运动（目的）
- 雨が降った**ために**中止した — 因为下雨而取消（原因）
- 不便**なために**人が減っている — 因为不便而人口减少（原因）

## 核心用法详解

### 用法一：表目的——为了……
语义：为了主动实现前项的目标，刻意采取后项的意志性行动。

典型例句：
- 日本に留学する**ために**、毎日8時間日本語を勉強している — 为了去日本留学，每天学8小时日语
- 健康**のために**、毎朝30分散歩する — 为了健康，每天早上散步30分钟

避坑提示：**表目的时前后句主语必须一致**。前项必须是意志性动词，表示主动朝着目标努力。

### 用法二：表原因——由于/因为……
语义：由于客观存在的事实，导致后项出现不理想的既定结果。

典型例句：
- 雨が降らな**いために**、畑の作物が枯れてしまった — 因为一直不下雨，田里的庄稼都旱死了
- 交通が不便**なために**、この町の人口はどんどん減っている — 因为交通不便，这个小镇的人口越来越少

避坑提示：**表原因时后项只能接既定事实**，不能接命令、劝诱、推测类表达。

## 注意
- 表目的时前后主语必须一致；表原因时后项只能接既定事实
- 「ために」书面感强，「から」口语化程度高
- 后续接名词时用「ための + 名词」形式，如「君のためのプレゼント」（为你准备的礼物）
- 中高级阶段的「～ため～ため」固定搭配表"既……又……"，属于N2扩展用法

## 易混近义句型辨析

| 对比项 | 「ために」（目的） | 「ように」（目的） |
|--------|-------------------|-------------------|
| 前项动词 | 意志性动词 | 非意志性状态动词 |
| 主语关系 | 前后主语必须一致 | 前后主语可以不一致 |
| 例句 | 合格するために勉強する | 合格できるように頑張る |

| 对比项 | 「ために」（原因） | 「から」 |
|--------|-------------------|---------|
| 语体 | 书面感强 | 口语化程度高 |
| 后项限制 | 只能接既定事实 | 可接任意类型表达 |
| 例句 | 雨のために中止した | 雨だから中止した |
