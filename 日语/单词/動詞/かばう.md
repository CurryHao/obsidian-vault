# 单词：かばう

## 基础核心信息
- **词性与语义：** 他动词・五段动词；核心是「替人挡住外界的指责/伤害」，常带「偏袒、护短」语感
- **汉字写法：** 庇う（高考专项考汉字：干扰项「護う」「擁う」「癖う」，正确只有「庇う」）
- **反义词：** 責める（せめる）指责、追责
- **派生名词：** 庇い（かばい）庇护、袒护的行为

## 核心固定用法

### 袒护、包庇他人
**语义：** 最高频核心义项。主动替犯错的人遮挡指责、承担责任，不让对方受到批评惩罚。

典型例句：
- 父にしかられていたら、母が「わざとやったわけじゃないんだから」と言って庇ってくれた。— 我被爸爸骂的时候，妈妈总会护着我说「他又不是故意的」。
- 上司のミスを庇うために、自分が責任を取った。— 为了袒护上司的失误，我自己担下了责任。

### 护住身体部位
**语义：** 下意识护住受伤、疼痛的部位，避免二次受伤。

典型例句：
- あの選手は怪我した足を庇いつつ最後まで完走した。— 那位选手边护着受伤的脚边坚持跑到了最后。
- 転んだ瞬間、頭を庇った。— 摔倒的瞬间，我下意识护住了头。

### 保护弱者
**语义：** 主动站出来替弱势群体挡住外界的伤害、不公待遇。

典型例句：
- 弱い者を庇う。— 保护弱者。

## 近义核心辨析

### かばう vs 護る（まもる）
「かばう」核心是替人挡掉外界的指责、伤害，甚至主动替对方担责，带「偏袒、护短」语感；「護る」是通用的「守护、保护人/事物的安全」，没有「偏袒犯错者」的含义。

| | かばう | 護る |
|---|---|---|
| 对象 | 犯错/受指责的人 | 人/物（安全对象） |
| 语感 | 偏袒、护短，可能担责 | 中性守护 |
| 典型场景 | 上司のミスをかばう | 家族を守る |
