# 📝 N2 诊断性自测流程（自适应版）

> **核心理念**：根据实时表现动态调整难度，精准定位薄弱点
> **优势**：避免"太简单浪费时间、太难打击信心"，找到你的真实水平线

---

## 🎯 自适应机制

### 难度调节规则

| 连续正确 | 下题难度 | 说明 |
|----------|----------|------|
| 3+ 题正确 | ⬆️ 提升 | 你掌握较好，加大挑战 |
| 0-1 题正确 | ⬇️ 降低 | 回归基础，巩固核心 |
| 2 题正确 | ➡️ 保持 | 维持当前难度 |

### 题目数量调节

| 场景 | 题目数 | 原因 |
|------|--------|------|
| 初期测试 | 15 题/模块 | 快速摸底，避免疲劳 |
| 稳定表现 | 30 题/模块 | 完整诊断 |
| 薄弱专项 | 20 题/专题 | 深度突破 |

---

## 🤖 自适应 Prompt 模板

```
你是一位专业的 JLPT N2 考试教练，采用自适应测试方法。

## 测试规则
1. 从 N5 基础语法开始，逐步提升到 N2 难度
2. 每 5 题暂停一次，询问我是否继续或调整难度
3. 如果我连续答对 3 题，下一轮提高难度
4. 如果我连续答错 2 题，下一轮降低难度或回到基础
5. 每个模块先做 15 题摸底，表现好再加量到 30 题

## 测试模块（按顺序）
1. 文法（从 N5-N4 基础开始）
2. 词汇（从常见词开始）
3. 汉字（从基础读音开始）

## 开始
请先出第 1 道文法题（N5 难度）。
```

## 📝 分步流程

### 第一阶段：摸底测试（15 题）

**Prompt：**
```
请先进行摸底测试。每个模块出 15 题，从基础难度开始。
每 5 题后暂停，告诉我当前正确率，问我是否：
- 继续同一难度
- 提升难度
- 降低难度
- 结束该模块
```

**示例交互：**
```
【第 1-5 题】文法 N5 基础
你的正确率：5/5 (100%)

当前表现优秀，建议：
A. 继续同一难度（再做 5 题）
B. 提升难度到 N4
C. 结束文法模块
请选择：
```

### 第二阶段：精准定位（根据摸底结果）

**场景 A：全对 → 直接上 N2 真题难度**
```
摸底表现优秀，直接进入 N2 核心语法测试。
出 15 道 N2 文法题，重点考察：
- 接续规则辨析
- 近义语法区分
- 语境应用
```

**场景 B：部分错 → 针对性补基础**
```
发现「～わけにはいかない」类语法错误较多。
请针对「消极否定」类语法出题，出 10 题巩固。
```

**场景 C：基础薄弱 → 回溯 N4/N5**
```
连续答错，需要回溯基础。
请出 10 道 N4 文法题，重点考察基础接续。
```

### 第三阶段：生成报告

```
测试完成。请输出：

1. 【能力评估】
   - 文法：当前水平（N4/N3/N2）+ 正确率曲线
   - 词汇：当前水平 + 薄弱类别
   - 汉字：当前水平 + 问题类型

2. 【动态调整记录】
   - 每阶段的难度变化
   - 连续正确/错误次数
   - 最终定位难度

3. 【Phase 1 学习建议】
   - 根据实时表现，推荐优先级
   - 具体需要补的基础点
```

## 🎯 三种自适应模式

### 模式 A：稳扎稳打（推荐初次使用）

```
请按以下节奏测试：
1. 每个模块先出 10 题基础难度
2. 根据正确率决定后续：
   - ≥80% → 提升到 N2 难度，再做 10 题
   - 50-79% → 保持当前难度，再做 10 题巩固
   - <50% → 降低难度，回溯基础
3. 每个模块结束后生成该模块的详细报告
```

### 模式 B：快速摸底

```
请快速摸底，每个模块只出 10 题。
第 1 题基础难度，根据我的回答动态调整：
- 答对 → 下一题难一点
- 答错 → 下一题简单一点
10 题后告诉我你的判断：我的水平大概在什么等级？
```

### 模式 C：弱点歼灭

```
我已知自己的薄弱点是「～ばよかった」类语法。
请针对这个弱点出题，出 15 题。
每道题都要考察不同的变体：
- ～ばよかった vs ～なければよかった
- ～ばよかった vs ～ば良かった（旧字体）
- 与其他否定语法的区别

出完 15 题后，告诉我哪些变体我还容易混淆。
```

## 🔄 多次自测对比

自适应测试的优势在于**可重复、可对比**：

| 自测次数 | 文法水平 | 词汇水平 | 汉字水平 | 趋势 |
|----------|----------|----------|----------|------|
| 第 1 次 | N4 → N3 | N4 | N4 | — |
| 第 2 次（2周后）| N3 | N3 → N2 | N4 → N3 | ⬆️ 进步 |
| 第 3 次（1月后）| N2 | N2 | N3 | ⬆️ 稳定 |

**使用建议**：
- 每 2 周做一次自适应自测
- 记录每次的「最终定位水平」
- 绘制水平曲线图，直观看到进步

## 📎 附录：快捷 Prompt 库

### 日常练习（5 分钟）
```
出 5 道 N2 文法题，考察「～ものだ」系列。
我答完后立即批改，不对的给出例句。
```

### 周末强化（30 分钟）
```
进行完整自适应测试：
1. 文法 15 题（从 N4 开始）
2. 词汇 15 题
3. 汉字 10 题
每模块结束后总结，最后生成整体报告。
```

### 考前冲刺（15 分钟）
```
随机出 10 道 N2 真题风格的题目，混合文法、词汇、汉字。
限时 10 分钟，出完立即批改。
```

---

> 💡 **提示**：自适应测试的核心是「找到你的水平线」。第一次可能不太准，但 2-3 次后会越来越精准。关键是每次都要诚实回答，不要猜测。
