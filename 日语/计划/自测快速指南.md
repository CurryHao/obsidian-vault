## 三种模式

| 模式 | 适用场景 | Prompt 摘要 |
|------|----------|------------|
| **baseline**(摸底) | 首次测试 / 基础不牢 | 从 N5 开始逐步到 N4 |
| **adaptive**(自适应) | 已稳定在 N3 附近 | N4→N2 动态升降 |
| **sprint**(冲刺) | 三项均达 N2 水平 | N2 真题模拟 |

> 具体模式怎么选?直接跑下面的启动脚本,它会根据历史推荐。

---

## 快速启动

```bash
# 启动自测(脚本会自动根据历史推荐模式 + 生成 Prompt + 建日志模板)
bash ~/桌面/TechVault/日语/脚本/n2_adaptive_start.sh

# 复制 Prompt 到 DeepTutor http://localhost:3782
# 完成测试后,记录结果
python3 ~/桌面/TechVault/日语/脚本/n2_assessment_tracker.py add \
  --date 2026-09-03 --mode adaptive \
  --grammar-level N3 --grammar-correct 12 --grammar-total 15 \
  --vocab-level   N3 --vocab-correct   10 --vocab-total   15 \
  --kanji-level   N4 --kanji-correct    6 --kanji-total   10

# 查看进度
python3 ~/桌面/TechVault/日语/脚本/n2_assessment_tracker.py progress

# 生成首末对比报告(需要 >=2 条记录)
python3 ~/桌面/TechVault/日语/脚本/n2_assessment_tracker.py report
```

---

## add 命令参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| `--date` | ✅ | 测试日期 YYYY-MM-DD |
| `--mode` | ✅ | `baseline` / `adaptive` / `sprint` |
| `--grammar-level` | 可选 | N5/N4/N3/N2,省略则视为未测 |
| `--grammar-correct` | 配合 level | 正确数 |
| `--grammar-total` | 配合 level | 总题数 |
| `--vocab-level` / `--vocab-correct` / `--vocab-total` | 同上 | 词汇模块 |
| `--kanji-level` / `--kanji-correct` / `--kanji-total` | 同上 | 汉字模块 |

每个模块三件套必须同时给(level + correct + total);某个模块没测就整套省略。三个模块至少要有一个。

启动脚本 `n2_adaptive_start.sh` 跑完后会在末尾输出针对本次推荐的命令模板,直接复制填数字即可。

## 进度/报告输出说明

- `progress` —— 列出每次自测的日期 + 模式 + 三个模块的等级 + 正确率,1 条记录也显示
- `report` —— 生成首次 vs 最近的水平变化对比,需要至少 2 条记录
- 历史数据存在 `日语/计划/自测历史记录.json`(脚本自动维护)
