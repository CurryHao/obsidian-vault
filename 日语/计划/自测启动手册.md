# 🚀 N2 自测启动手册

> 打开 DeepTutor 后,按这个流程操作。如果只是想看哪种模式适合,直接看 [[自测快速指南]]。

---

## 第一步:打开 DeepTutor

```bash
# 本机访问(默认)
http://localhost:3782

# 远程访问:端口以 frp 当前映射为准,动态查询
frpc 状态: cat ~/.config/frp/frpc.toml | grep deeptutor
# 或直接看 start.sh 推荐后的输出里附带的远程入口(如有)
```

> 🔐 **登录密码** 不在本文件硬编码,统一从 `~/.hermes/secrets/deeptutor-password.txt` 或 Vaultwarden 取,避免 vault 分享时泄露。

---

## 第二步:新建对话

点击右上角 **"New Chat"** / **"新建对话"**

标题建议:`N2自测-YYYY-MM-DD`(方便后面查找)

---

## 第三步:发送初始化 Prompt

```bash
# 推荐方式:跑启动脚本,自动生成 Prompt
bash ~/桌面/TechVault/日语/脚本/n2_adaptive_start.sh

# 复制输出的 Prompt 段(从 ───── 行之间复制)
```

或手动复制启动手册里 7.x 版本的 Prompt(见下方「快捷 Prompt 库」)。

---

## 第四步:答题

DeepTutor 会出一道题,格式类似:

```
【文法第 1 题】
次の文の（ ）に入れるのに最もよいものを選ばなさい。
彼は忙しくて、昨日は食べ（ （ ））できなかった。
A. しなければならない   B. わけにはいかない
C. わけではない         D. はずがない
```

**你的回复**:直接发选项字母

```
B
```

DeepTutor 会判断对错并给出解析,然后出下一题。

---

## 第五步:每 5 题暂停时的交互

```
【第 1-5 题完成】
正确率:4/5 (80%)
A. 继续同一难度
B. 提升难度
C. 降低难度
D. 结束文法模块
```

**根据情况回复**:
- 全对 → `B`(提升)
- 有错 → `A` 或 `C`
- 想换模块 → `D`

> ⚠️ **如果 DeepTutor 开始"讲课"或追问**(teacher 模式),直接回 `出下一题` 或 `按规则继续`,不要被带跑。

---

## 第六步:模块切换

```
开始词汇测试
```

---

## 第七步:生成报告

所有模块完成后,发送:

```
测试完成。请输出:
1. 各模块得分和正确率
2. 薄弱点分析(具体到语法点/词汇类别)
3. Phase 1 学习建议
4. 待补充笔记清单(格式:词条 + 问题描述)
```

---

## 第八步:记录结果

```bash
# 把结果写入 tracker(自动更新历史 + 支持 progress / report 对比)
python3 ~/桌面/TechVault/日语/脚本/n2_assessment_tracker.py add \
  --date 2026-09-03 --mode adaptive \
  --grammar-level N3 --grammar-correct 12 --grammar-total 15 \
  --vocab-level   N3 --vocab-correct   10 --vocab-total   15 \
  --kanji-level   N4 --kanji-correct    6 --kanji-total   10

# 查看进度
python3 ~/桌面/TechVault/日语/脚本/n2_assessment_tracker.py progress

# 生成首末对比
python3 ~/桌面/TechVault/日语/脚本/n2_assessment_tracker.py report

# 同时在 Obsidian 日志里写当日详情
~/桌面/TechVault/日语/日志/YYYY-MM-DD-N2自测.md
```

## 常见问题

### Q: DeepTutor 不回复?

```bash
curl -s http://localhost:8001/    # 检查 API
# 如需重启
cd ~/projects/deeptutor && docker compose restart deeptutor
```

### Q: 题目太简单/太难?

直接告诉 DeepTutor:
```
太简单了,请直接出 N2 真题难度的题
```
或
```
太难了,回到 N4 基础题
```

### Q: 想只测某个模块?

```
跳过文法,直接开始词汇测试,出 20 题
```

### Q: 中途想结束?

```
测试结束,请生成报告
```

## 快捷 Prompt 库

### 模式 1:稳扎稳打(推荐首次使用)

```
你是一位专业的 JLPT N2 考试教练。请进行自适应测试:
1. 每个模块先出 10 题基础难度(N4-N5)
2. 每 5 题后暂停,询问我是否继续
3. 正确率≥80% 则提升难度,<50% 则降低
4. 三个模块:文法、词汇、汉字
5. 最后输出薄弱点分析和 Phase 1 建议
```

### 模式 2:快速摸底(时间紧)

```
请快速摸底测试,每个模块只出 10 题。
第 1 题基础难度,根据我的回答动态调整。
10 题后告诉我:我的水平大概在什么等级?
```

### 模式 3:专项突破(已知薄弱点)

```
我的薄弱点是「～わけにはいかない」类语法。
请针对这个弱点出 15 题,考察不同变体。
```

### 模式 4:冲刺模拟(已定级 N2)

```
你是一位专业的JLPT N2 考试教练。我需要进行考前冲刺模拟测试。
1. 文法 30 题(N2 真题难度,混合所有语法点)
2. 词汇 30 题(N2 高频词,含惯用语)
3. 汉字 20 题(N2 音读/训读/用法)
4. 每 10 题暂停一次
5. 完成后生成详细分析报告
```
